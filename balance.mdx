title: "Account Balance"
description: "Query account balances and ledger information"
---


Query detailed account information including balances by ledger type, account status, and configured payment methods.

## Endpoint

```http
GET /api/v1/accounts/balance
```

## Query Parameters

| Parameter | Type | Required | Description | Values |
|-----------|------|----------|-------------|--------|
| `refresh` | boolean | ❌ | Force cache refresh | `true`, `false` |

<Info>
  The `refresh=true` parameter forces real-time data retrieval, bypassing the 30-minute cache.
</Info>

## Response

<Response>
  <Title>AccountBalanceResponse</Title>
  ```json
  {
    "accountNumber": "1234567890",
    "isActive": true,
    "balances": {
      "BRL_AVAILABLE": {
        "total": "10000.50",
        "available": "9500.00",
        "hold": "500.50"
      },
      "USDT_AVAILABLE": {
        "total": "5000.00",
        "available": "4850.00",
        "hold": "150.00"
      },
      "BTC_AVAILABLE": {
        "total": "0.125",
        "available": "0.120",
        "hold": "0.005"
      }
    }
  }
  ```
</Response>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `accountNumber` | string | Account number |
| `isActive` | boolean | Account status (active/inactive) |
| `balances` | object | Balances by ledger type |
| `balances[ledgerType].total` | decimal | Total balance in the ledger |
| `balances[ledgerType].available` | decimal | Available balance for use |
| `balances[ledgerType].hold` | decimal | Balance blocked due to regulatory requirements |

## Supported Ledger Types

| Ledger Type | Description | Currency |
|-------------|-------------|----------|
| `BRL_AVAILABLE` | Brazilian Real balance | BRL |
| `USDT_AVAILABLE` | USDT balance | USD |
| `BTC_AVAILABLE` | Bitcoin balance | USD |

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Balance retrieved successfully |
| `401` | Unauthorized |
| `500` | Internal server error |

## Examples

### cURL

```bash
# Get cached balance
curl -X GET "https://api.monkei.co/api/v1/accounts/balance" \
  -H "X-API-Key: sk_live_1234567890abcdef"

# Force refresh
curl -X GET "https://api.monkei.co/api/v1/accounts/balance?refresh=true" \
  -H "X-API-Key: sk_live_1234567890abcdef"
```

### JavaScript

```javascript
async function getAccountBalance(refresh = false) {
  const params = new URLSearchParams();
  if (refresh) {
    params.append('refresh', 'true');
  }

  const response = await fetch(
    `https://api.monkei.co/api/v1/accounts/balance?${params}`,
    {
      headers: {
        'X-API-Key': 'sk_live_1234567890abcdef'
      }
    }
  );

  return await response.json();
}

// Get cached balance
const balance = await getAccountBalance();
console.log('BRL Available:', balance.balances.BRL_AVAILABLE.available);

// Force refresh
const freshBalance = await getAccountBalance(true);
console.log('Updated BRL Available:', freshBalance.balances.BRL_AVAILABLE.available);
```

### Python

```python
import requests

def get_account_balance(refresh=False):
    headers = {
        'X-API-Key': 'sk_live_1234567890abcdef'
    }
    
    params = {}
    if refresh:
        params['refresh'] = 'true'
    
    response = requests.get(
        'https://api.monkei.co/api/v1/accounts/balance',
        headers=headers,
        params=params
    )
    
    return response.json()

# Get cached balance
balance = get_account_balance()
print(f"BRL Available: {balance['balances']['BRL_AVAILABLE']['available']}")

# Force refresh
fresh_balance = get_account_balance(refresh=True)
print(f"Updated BRL Available: {fresh_balance['balances']['BRL_AVAILABLE']['available']}")
```

## Understanding Balances

### Total Balance

The total balance represents the complete amount in a ledger, including both available and hold amounts:

```
total = available + hold
```

### Available Balance

The available balance represents funds received from payments. You can withdraw this balance to:

- Your bank account (via PIX)
- Your cryptocurrency wallet (BTC or USDT)

### Hold Balance

The hold balance represents funds blocked due to regulatory requirements.

## Caching

By default, balance data is cached for 30 minutes to improve performance. Use the `refresh=true` parameter when you need real-time data:

<Warning>
  Force refreshing bypasses the cache and queries the database directly. Use sparingly to avoid performance impact.
</Warning>

## Use Cases

### Check Balance Before Payment

```javascript
async function checkBalanceBeforePayment(amount) {
  const balance = await getAccountBalance();
  const available = parseFloat(balance.balances.BRL_AVAILABLE.available);
  
  if (available >= amount) {
    // Proceed with payment
    return true;
  } else {
    throw new Error('Insufficient balance');
  }
}
```

### Monitor Balance Changes

```javascript
async function monitorBalance() {
  let previousBalance = null;
  
  setInterval(async () => {
    const currentBalance = await getAccountBalance(true); // Force refresh
    const current = parseFloat(currentBalance.balances.BRL_AVAILABLE.available);
    
    if (previousBalance !== null && current !== previousBalance) {
      console.log(`Balance changed: ${previousBalance} → ${current}`);
    }
    
    previousBalance = current;
  }, 60000); // Check every minute
}

```
