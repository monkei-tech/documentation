# Coupons Overview

The Coupons API allows you to create, manage, and validate discount coupons for your bills. Coupons can offer percentage discounts, fixed amount discounts, or free shipping.

## What are Coupons?

Coupons are discount codes that customers can apply to bills during checkout. They help you attract customers, reward loyalty, and run promotional campaigns.

<Note>
  Coupons can be used with bills that have `allow_coupon` set to `true`. You can also restrict which coupon codes are allowed per bill.
</Note>

## Discount Types

### Percentage Discount

Apply a percentage discount to the bill total. The discount value must be between 0 and 100.

**Example**: A 10% discount means `discount_value: 10`

### Fixed Discount

Apply a fixed amount discount in cents. The discount value must be between 0 and 1,000,000 cents (R$10,000.00).

**Example**: A R$5.00 discount means `discount_value: 500`

### Free Shipping

Offer free shipping. The discount value must be 0.

**Example**: `discount_kind: "FREE_SHIPPING"` with `discount_value: 0`

## Coupon Statuses

| Status | Description |
|--------|-------------|
| `ACTIVE` | Coupon is active and can be used |
| `INACTIVE` | Coupon is inactive and cannot be used |
| `MAX_REDEEMS_REACHED` | Coupon has reached its maximum redemption limit |

## Use Cases

- **Promotional Campaigns**: Create limited-time discount codes
- **Customer Retention**: Reward loyal customers with special codes
- **Seasonal Sales**: Run holiday or seasonal promotions
- **Referral Programs**: Offer discounts for referrals

## Getting Started

<Steps>
  <Step title="Create a Coupon">
    Use the <a href="/coupons/create">Create Coupon</a> endpoint to generate a new discount code.
  </Step>
  <Step title="Configure Bills">
    Enable coupon usage in your bills by setting `allow_coupon: true` and optionally specifying `coupons_allowed`.
  </Step>
  <Step title="Validate Coupons">
    Use the validation endpoint to check if a coupon is valid before applying it.
  </Step>
</Steps>
