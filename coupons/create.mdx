---
title: "Create Coupon"
description: "Create a new discount coupon"
---


Create a new discount coupon with a code, discount type, and maximum redemption limit.

## Endpoint

```http
POST /api/dashboard/v1/coupons
```

## Request

<Request>
  <Title>CreateCouponRequest</Title>
  ```json
  {
    "code": "WELCOME10",
    "description": "Welcome discount 10% off",
    "discount_kind": "PERCENTAGE",
    "discount_value": 10,
    "max_redeems": 100
  }
  ```
</Request>

## Parameters

| Field | Type | Required | Description | Values |
|-------|------|----------|-------------|--------|
| `code` | string | ✅ | Coupon code | Unique code |
| `description` | string | ❌ | Coupon description | Text description |
| `discount_kind` | string | ✅ | Type of discount | `"PERCENTAGE"` |
| `discount_value` | integer | ✅ | Discount value | See below |
| `max_redeems` | integer | ✅ | Maximum redemptions | `min=1` |

### Discount Value Rules

| Discount Kind | Min Value | Max Value | Description |
|---------------|-----------|-----------|-------------|
| `PERCENTAGE` | 1 | 100 | Percentage discount (1-100%) |

<Warning>
  The discount value must be valid for the selected discount kind. Invalid combinations will be rejected.
</Warning>

<Response>
  <Title>CreateCouponResponse</Title>

  ```json
  {
    "coupon": {
      "code": "WELCOME10",
      "description": "Welcome discount 10% off",
      "discount_kind": "PERCENTAGE",
      "discount_value": 10,
      "max_redeems": 100,
      "status": "ACTIVE",
      "created_at": "2024-01-01T12:00:00Z",
      "updated_at": "2024-01-01T12:00:00Z"
    }
  }
  ```
</Response>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | Coupon created successfully |
| `400` | Bad request - validation error or invalid data |
| `401` | Unauthorized |
| `500` | Internal server error |

## Examples

### cURL

```bash
curl -X POST https://api.monkei.com/api/dashboard/v1/coupons \
  -H "Authorization: Bearer sk_live_1234567890abcdef" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "WELCOME10",
    "description": "Welcome discount 10% off",
    "discount_kind": "PERCENTAGE",
    "discount_value": 10,
    "max_redeems": 100
  }'
```

### JavaScript

```javascript
async function createCoupon() {
  const response = await fetch('https://api.monkei.com/api/dashboard/v1/coupons', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer sk_live_1234567890abcdef',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      code: 'WELCOME10',
      description: 'Welcome discount 10% off',
      discount_kind: 'PERCENTAGE',
      discount_value: 10,
      max_redeems: 100
    })
  });

  const result = await response.json();
  return result.coupon;
}
```

### Python

```python
import requests

def create_coupon():
    headers = {
        'Authorization': 'Bearer sk_live_1234567890abcdef',
        'Content-Type': 'application/json'
    }
    
    data = {
        'code': 'WELCOME10',
        'description': 'Welcome discount 10% off',
        'discount_kind': 'PERCENTAGE',
        'discount_value': 10,
        'max_redeems': 100
    }
    
    response = requests.post(
        'https://api.monkei.com/api/dashboard/v1/coupons',
        headers=headers,
        json=data
    )
    
    return response.json()['coupon']
```

## Discount Kind Examples

### Percentage Discount

```json
{
  "code": "SAVE20",
  "discount_kind": "PERCENTAGE",
  "discount_value": 20,
  "max_redeems": 50
}
```

Applies a 20% discount to the bill total.

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `INVALID_DISCOUNT_KIND` | Invalid discount kind | Use PERCENTAGE only |
| `INVALID_DISCOUNT` | Invalid discount value | Ensure value matches discount kind rules |
| `INVALID_MAX_REDEEMS` | Invalid max redeems | Must be at least 1 |

### Error Response

```json
{
  "error": "VALIDATION_ERROR",
  "message": "Request validation failed",
  "code": 400,
  "operation": "coupon.ValidateRequest"
}
```

## Best Practices

1. **Unique Codes**: Use descriptive, memorable codes that are easy for customers to remember
2. **Reasonable Limits**: Set appropriate `max_redeems` based on your campaign goals
3. **Clear Descriptions**: Provide clear descriptions to help identify coupons later
4. **Test First**: Create test coupons with small limits before launching campaigns
