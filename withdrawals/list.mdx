# List Withdrawals

Retrieve a paginated list of withdrawals with optional filtering by status, method, and date range.

## Endpoint

```http
GET /api/v1/transactions/withdrawals
```

## Query Parameters

| Parameter | Type | Required | Description | Values |
|-----------|------|----------|-------------|--------|
| `status` | string | ❌ | Filter by status | `"PENDING"`, `"PROCESSING"`, `"SETTLED"`, `"FAILED"` |
| `method` | string | ❌ | Filter by method | `"PIX"`, `"BTC"`, `"USDT"` |
| `currency` | string | ❌ | Filter by currency | `"BRL"`, `"USD"` |
| `start_date` | string | ❌ | Start date filter | ISO 8601 format |
| `end_date` | string | ❌ | End date filter | ISO 8601 format |
| `page` | integer | ❌ | Page number | `1` (default) |
| `limit` | integer | ❌ | Items per page | `10` (default, max: 100) |

## Example Request

```http
GET /api/v1/transactions/withdrawals?status=SETTLED&method=PIX&page=1&limit=20
```

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Withdrawals retrieved successfully |
| `400` | Bad request - invalid parameters |
| `401` | Unauthorized |
| `500` | Internal server error |

## Examples

### cURL

```bash
curl -X GET "https://api.monkei.com/api/v1/transactions/withdrawals?status=SETTLED&method=PIX&page=1&limit=20" \
  -H "Authorization: Bearer sk_live_1234567890abcdef"
```

### JavaScript

```javascript
async function listWithdrawals(status = 'SETTLED', page = 1) {
  const params = new URLSearchParams({
    status,
    page: page.toString(),
    limit: '20'
  });

  const response = await fetch(
    `https://api.monkei.com/api/v1/transactions/withdrawals?${params}`,
    {
      headers: {
        'Authorization': 'Bearer sk_live_1234567890abcdef'
      }
    }
  );

  const { data, pagination } = await response.json();
  return { withdrawals: data, pagination };
}

// List settled withdrawals
const { withdrawals, pagination } = await listWithdrawals('SETTLED');
console.log(`Total withdrawals: ${pagination.total}`);
```

### Python

```python
import requests

def list_withdrawals(status='SETTLED', page=1, limit=20):
    headers = {
        'Authorization': 'Bearer sk_live_1234567890abcdef'
    }
    
    params = {
        'status': status,
        'page': page,
        'limit': limit
    }
    
    response = requests.get(
        'https://api.monkei.com/api/v1/transactions/withdrawals',
        headers=headers,
        params=params
    )
    
    return response.json()

# List settled withdrawals
result = list_withdrawals('SETTLED', page=1)
print(f"Total withdrawals: {result['pagination']['total']}")
```

## Filtering

### By Status

Filter withdrawals by their current status:

- `PENDING` - Withdrawal created, awaiting processing
- `PROCESSING` - Withdrawal being processed
- `SETTLED` - Withdrawal completed successfully
- `FAILED` - Withdrawal failed

### By Method

Filter withdrawals by payment method:

- `PIX` - PIX withdrawals
- `BTC` - Bitcoin withdrawals
- `USDT` - USDT withdrawals

### By Date Range

Filter withdrawals by creation date:

```http
GET /api/v1/transactions/withdrawals?start_date=2024-01-01T00:00:00Z&end_date=2024-01-31T23:59:59Z
```

## Pagination

The response includes pagination information:

- `page`: Current page number (starts at 1)
- `limit`: Number of items per page (max: 100)
- `total`: Total number of withdrawals matching the filters
- `total_pages`: Total number of pages

<Info>
  The default page size is 10 items. You can increase it up to 100 items per page for better performance when dealing with large datasets.
</Info>
