Retrieve information about your account's daily and monthly limits, including how much you've used and how much remains available.

## Endpoint

```http
GET /api/dashboard/v1/account/limits
```

## Overview

The limits endpoint provides detailed information about your account's usage limits. This includes daily and monthly limits for withdrawals and deposits, showing both the total limit amount and how much you've already used.

<Warning>
  **Important**: All limits are denominated in **US Dollars (USD)**. The default limit starts at **$1,000 USD**. To increase your limits, please contact our support team.
</Warning>

<Info>
  Limits are automatically reset daily or monthly based on the limit type. Check the `reset_date` field to know when limits will reset.
</Info>


## Limit Types

| Limit Type | Description |
|------------|-------------|
| `WITHDRAW_DAILY` | Daily withdrawal limit |
| `WITHDRAW_MONTHLY` | Monthly withdrawal limit |
| `DEPOSIT_DAILY` | Daily deposit limit |
| `DEPOSIT_MONTHLY` | Monthly deposit limit |
| `WITHDRAW_USDT_DAILY` | Daily USDT withdrawal limit |
| `WITHDRAW_BTC_DAILY` | Daily BTC withdrawal limit |
| `DEPOSIT_BTC_DAILY` | Daily BTC deposit limit |

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `daily_limits` | array | Array of daily limit objects |
| `total` | integer | Total number of limits found |

### Daily Limit Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique limit identifier (UUID) |
| `limit_type` | string | Type of limit (see Limit Types above) |
| `amount` | decimal | Total limit amount |
| `used_amount` | decimal | Amount already used |
| `remaining_amount` | decimal | Amount remaining (amount - used_amount) |
| `reset_date` | string | Date when the limit will reset (ISO 8601) |

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Limits retrieved successfully |
| `400` | Bad request - invalid parameters |
| `401` | Unauthorized |
| `500` | Internal server error |

### JavaScript

```javascript
async function getLimits() {
  const response = await fetch(
    'https://api.monkei.co/api/dashboard/v1/account/limits',
    {
      headers: {
        'X-API-Key': 'sk_live_1234567890abcdef'
      }
    }
  );

  const data = await response.json();
  return data.daily_limits;
}

// Get all limits
const limits = await getLimits();

// Check remaining amount for daily withdrawal
const dailyWithdraw = limits.find(l => l.limit_type === 'WITHDRAW_DAILY');
if (dailyWithdraw) {
  console.log(`Remaining: $${dailyWithdraw.remaining_amount} of $${dailyWithdraw.amount}`);
}
```

### Python

```python
import requests

def get_limits():
    headers = {

    response = requests.get(

```

## Understanding Limits

### Limit Calculation

The remaining amount is calculated as:

```
remaining_amount = amount - used_amount
```

### Limit Reset

Limits automatically reset based on their type:

- **Daily Limits**: Reset at midnight UTC each day
- **Monthly Limits**: Reset on the first day of each month at midnight UTC

The `reset_date` field shows when the next reset will occur.

### Usage Tracking

When you perform operations (withdrawals, deposits), the `used_amount` is automatically updated, and `remaining_amount` decreases accordingly.

<Warning>
  If `remaining_amount` is less than the amount you want to withdraw, the operation will be rejected. Always check your limits before creating withdrawals.
</Warning>

## Filtering Limits

The endpoint returns all limits for your account. You can filter the results in your application code:

```javascript
// Get all limits and filter by type
const limits = await getLimits();
const dailyWithdrawLimits = limits.filter(l => l.limit_type === 'WITHDRAW_DAILY');
const monthlyLimits = limits.filter(l => l.limit_type === 'WITHDRAW_MONTHLY');
const activeLimits = limits.filter(l => l.is_active === true);
```

## Use Cases

### Check Before Withdrawal

```javascript
async function canWithdraw(amount) {
  const limits = await getLimits();
  const dailyLimit = limits.find(l => l.limit_type === 'WITHDRAW_DAILY');
  
  if (!dailyLimit) {
    return { canWithdraw: false, reason: 'No limit configured' };
  }
  
  if (parseFloat(dailyLimit.remaining_amount) >= amount) {
    return { canWithdraw: true, remaining: dailyLimit.remaining_amount };
  } else {
    return {
      canWithdraw: false,
      reason: 'Insufficient limit',
      remaining: dailyLimit.remaining_amount,
      needed: amount
    };
  }
}

// Check before withdrawal
const check = await canWithdraw(500);
if (check.canWithdraw) {
  // Proceed with withdrawal
} else {
  console.log(`Cannot withdraw: ${check.reason}`);
}
```

### Monitor Limit Usage

```javascript
async function getLimitUsage() {
  const limits = await getLimits();
  
  return limits.map(limit => ({
    type: limit.limit_type,
    total: parseFloat(limit.amount),
    used: parseFloat(limit.used_amount),
    remaining: parseFloat(limit.remaining_amount),
    usagePercent: (parseFloat(limit.used_amount) / parseFloat(limit.amount)) * 100,
    resetDate: limit.reset_date
  }));
}

// Get usage summary
const usage = await getLimitUsage();
usage.forEach(u => {
  console.log(`${u.type}: ${u.usagePercent.toFixed(2)}% used (${u.remaining} remaining)`);
});
```
