The Billing API allows you to create, manage, and process one-time or recurring charges through multiple payment methods. It supports products, discount coupons, and transparent checkout processing.

## What is Billing?

Billing enables you to create invoices that customers can pay using PIX, Bitcoin, or USDT. You can configure multiple products per bill, apply discount coupons, and customize the checkout experience.

<Note>
  Bills can be used for one-time charges (ONE_TIME) or multiple payments (MULTIPLE_PAYMENTS), with support for coupons and different payment methods.
</Note>

## Use Cases

- **E-commerce**: Create invoices for online purchases
- **Subscription Services**: Set up recurring billing for subscriptions
- **Marketplace**: Generate bills for multiple vendors
- **SaaS Platforms**: Invoice customers for service usage

## Getting Started

<Steps>
  <Step title="Create a Bill">
    Use the <a href="/billing/create">Create Bill</a> endpoint to generate a new invoice with products and payment methods.
  </Step>
  <Step title="Share Payment URL">
    Customers receive a payment URL where they can complete the transaction using their preferred payment method.
  </Step>
  <Step title="Receive Webhooks">
    Get notified in real-time when bills are paid, canceled, or fail through webhook events.
  </Step>
</Steps>
