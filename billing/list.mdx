# List Bills

Retrieve a paginated list of bills with optional filtering by status, frequency, and account.

## Endpoint

```http
GET /api/v1/bills
```

## Query Parameters

| Parameter | Type | Required | Description | Values |
|-----------|------|----------|-------------|--------|
| `account_id` | string | ❌ | Filter by account (UUID) | Valid UUID |
| `status` | string | ❌ | Filter by status | `"PAID"`, `"ACTIVE"`, `"FAILED"`, `"CANCELED"` |
| `frequency` | string | ❌ | Filter by frequency | `"ONE_TIME"`, `"MULTIPLE_PAYMENTS"` |
| `page` | integer | ❌ | Page number | `1` (default) |
| `limit` | integer | ❌ | Items per page | `10` (default, max: 100) |

## Example Request

```http
GET /api/v1/bills?status=ACTIVE&frequency=ONE_TIME&page=1&limit=20
```

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Bills retrieved successfully |
| `400` | Bad request - invalid parameters |
| `401` | Unauthorized |
| `500` | Internal server error |

## Examples

### cURL

```bash
curl -X GET "https://api.monkei.com/api/v1/bills?status=ACTIVE&frequency=ONE_TIME&page=1&limit=20" \
  -H "Authorization: Bearer sk_live_1234567890abcdef"
```

### JavaScript

```javascript
async function listBills(status = 'ACTIVE', page = 1) {
  const params = new URLSearchParams({
    status,
    page: page.toString(),
    limit: '20'
  });

  const response = await fetch(
    `https://api.monkei.com/api/v1/bills?${params}`,
    {
      headers: {
        'Authorization': 'Bearer sk_live_1234567890abcdef'
      }
    }
  );

  const { data, pagination } = await response.json();
  return { bills: data, pagination };
}

// List active bills
const { bills, pagination } = await listBills('ACTIVE');
console.log(`Total bills: ${pagination.total}`);
```

### Python

```python
import requests

def list_bills(status='ACTIVE', page=1, limit=20):
    headers = {
        'Authorization': 'Bearer sk_live_1234567890abcdef'
    }
    
    params = {
        'status': status,
        'page': page,
        'limit': limit
    }
    
    response = requests.get(
        'https://api.monkei.com/api/v1/bills',
        headers=headers,
        params=params
    )
    
    return response.json()

# List active bills
result = list_bills('ACTIVE', page=1)
print(f"Total bills: {result['pagination']['total']}")
```

## Filtering

### By Status

Filter bills by their current status:

- `ACTIVE` - Active bills awaiting payment
- `PAID` - Bills that have been paid
- `FAILED` - Bills that failed processing
- `CANCELED` - Bills that were canceled

### By Frequency

Filter bills by their frequency type:

- `ONE_TIME` - Single payment bills
- `MULTIPLE_PAYMENTS` - Recurring payment bills

## Pagination

The response includes pagination information:

- `page`: Current page number (starts at 1)
- `limit`: Number of items per page (max: 100)
- `total`: Total number of bills matching the filters
- `total_pages`: Total number of pages

<Info>
  The default page size is 10 items. You can increase it up to 100 items per page for better performance when dealing with large datasets.
</Info>
