Create a new bill with customer information, payment methods, and products. All required fields must be provided.

## Endpoint

```http
POST /api/v1/bills
```

## Parameters

| Field | Type | Required | Description | Values |
|-------|------|----------|-------------|--------|
| `currency` | string | ❌ | Currency code | `"BRL"` (default), `"USD"` |
| `idiom` | string | ❌ | Language/idiom | `"pt-BR"` (default), `"en-US"` |
| `frequency` | string | ✅ | Billing frequency | `"ONE_TIME"`, `"MULTIPLE_PAYMENTS"` |
| `customer_data` | object | ✅ | Customer information | See below |
| `payment_methods` | array | ✅ | Allowed payment methods | `["PIX"]`, `["BTC"]`, `["USDT"]` |
| `metadata` | object | ❌ | Additional metadata | `{}` |
| `products` | array | ✅ | List of products | See below |
| `return_url` | string | ✅ | Return URL (cancellation) | Valid URL |
| `completion_url` | string | ✅ | Success URL (after payment) | Valid URL |
| `allow_coupon` | boolean | ❌ | Allow coupons | `false` (default) |
| `coupons_allowed` | array | ❌ | Allowed coupon codes | `["CODE1"]` |

<Info>
  **Currency**: The `currency` field determines which currency will be displayed and charged on the payment page. This affects how amounts are shown to customers (e.g., R$ for BRL, $ for USD).
</Info>

<Info>
  **Idiom**: The `idiom` field sets the primary language of the payment page. This controls the language of labels, messages, and interface elements shown to customers during checkout (e.g., "pt-BR" for Portuguese, "en-US" for English).
</Info>

### Customer Data

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `customer_id` | string | ❌ | Unique customer ID |
| `customer_metadata` | object | ❌ | Customer metadata |

### Customer Metadata

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ❌ | Customer full name |
| `phone` | string | ❌ | Phone with country code |
| `email` | string | ❌ | Valid email address |
| `tax_id` | string | ❌ | Customer CPF/CNPJ |

### Products

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `external_id` | string | ✅ | `max=100` | External product ID/SKU |
| `name` | string | ✅ | `max=100` | Product name |
| `description` | string | ❌ | `max=255` | Product description |
| `price` | integer | ✅ | `min=700` | Unit price in smallest unit (cents). Minimum: 700 cents (R$ 7.00 or $7.00) |
| `quantity` | integer | ✅ | `min=1` | Product quantity |
| `category` | string | ❌ | `max=100` | Product category |

<Warning>
  The minimum price per product is 700 cents (R$ 7.00 or $7.00). Values below will be rejected.
</Warning>

<Info>
  **Price**: The `price` field represents the product price in the smallest unit (cents). For example, `5000` represents R$ 50.00 when currency is BRL, or $50.00 when currency is USD.
</Info>

| Code | Description |
|------|-------------|

```python
import requests

def create_bill():
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': 'sk_live_1234567890abcdef'
    }
    
    data = {
        'currency': 'BRL',

        'frequency': 'ONE_TIME',
        'customer_data': {
            'customer_id': '12345678901',
            'customer_metadata': {
                'name': 'John Doe',
                'email': 'john@example.com',
                'tax_id': '12345678901'
            }
        },
        'payment_methods': ['PIX'],
        'products': [
            {
                'external_id': 'PLAN-PREMIUM-001',
                'name': 'Premium Plan',
                'description': 'Premium subscription plan',
                'price': 9990,  # R$ 99.90 in cents
                'quantity': 1
            }
        ],

        'completion_url': 'https://myapp.com/success',

        'https://api.monkei.co/api/v1/bills',
        headers=headers,
        json=data
    )
    
    return response.json()
```

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `VALIDATION_ERROR` | Price below minimum | Adjust to 700 cents (R$ 7.00 or $7.00) or more |
| `INVALID_PAYMENT_METHOD` | Invalid payment method | Use PIX, BTC or USDT |

### Error Response

```json
{
  "error": "VALIDATION_ERROR",
  "message": "Minimum price per product is 700 cents (R$ 7.00 or $7.00)",
  "details": "products[0].price must be greater than or equal to 700",
  "code": 400,
  "operation": "billing.Create"
}
```
