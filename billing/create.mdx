# Create Bill

Create a new bill with customer information, payment methods, and products. All required fields must be provided.

## Endpoint

```http
POST /api/v1/bills
```

## Parameters

| Field | Type | Required | Description | Values |
|-------|------|----------|-------------|--------|
| `frequency` | string | ✅ | Billing frequency | `"ONE_TIME"`, `"MULTIPLE_PAYMENTS"` |
| `customer_data` | object | ✅ | Customer information | See below |
| `payment_methods` | array | ✅ | Allowed payment methods | `["PIX"]`, `["BITCOIN"]`, `["USDT"]` |
| `metadata` | object | ❌ | Additional metadata | `{}` |
| `products` | array | ✅ | List of products | See below |
| `return_url` | string | ✅ | Return URL (cancellation) | Valid URL |
| `completion_url` | string | ✅ | Success URL (after payment) | Valid URL |
| `is_transparent` | boolean | ❌ | Transparent checkout | `false` (default) |
| `allow_coupon` | boolean | ❌ | Allow coupons | `false` (default) |
| `coupons_allowed` | array | ❌ | Allowed coupon codes | `["CODE1"]` |

### Customer Data

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `customer_id` | string | ❌ | Unique customer ID |
| `customer_metadata` | object | ❌ | Customer metadata |

### Customer Metadata

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | ❌ | Customer full name |
| `phone` | string | ❌ | Phone with country code |
| `email` | string | ❌ | Valid email address |
| `tax_id` | string | ❌ | Customer CPF/CNPJ |

### Products

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `id` | string | ✅ | - | Internal product ID |
| `external_id` | string | ✅ | - | External product ID/SKU |
| `price` | decimal | ✅ | `min=5.00` | Unit price (min: R$5.00) |
| `quantity` | integer | ✅ | `min=1` | Product quantity |

<Warning>
  The minimum price per product is R$5.00 (500 cents). Values below will be rejected.
</Warning>

```python
import requests

def create_bill():
    headers = {
        'Authorization': 'Bearer sk_live_1234567890abcdef',

    }
    
    data = {

        'customer_data': {
            'customer_id': '12345678901',
            'customer_metadata': {
                'name': 'John Doe',
                'email': 'john@example.com',
                'tax_id': '12345678901'
            }
        },
        'payment_methods': ['PIX'],
        'products': [
            {
                'id': 'premium_plan',
                'external_id': 'PLAN-PREMIUM-001',
                'price': 99.90,
                'quantity': 1
            }
        ],
        'return_url': 'https://myapp.com/cancel',
        'completion_url': 'https://myapp.com/success',
        'allow_coupon': True
    }
    
    response = requests.post(
        'https://api.monkei.com/api/v1/bills',
        headers=headers,
        json=data
    )
    
    return response.json()
```

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `PRODUCT_PRICE_TOO_LOW` | Price below minimum | Adjust to R$5.00 or more |
| `INVALID_PAYMENT_METHOD` | Invalid payment method | Use PIX, BITCOIN or USDT |

### Error Response

```json
{
  "error": "VALIDATION_ERROR",
  "message": "Minimum price per product is R$5.00",
  "details": "products[0].price must be greater than or equal to 500",
  "code": 400,
  "operation": "billing.Create"
}
```
