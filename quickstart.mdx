Start accepting crypto payments in your application in less than 5 minutes.

## 1. Create your account

To get started, you need a Monkei account. If you don't have one yet, create it now:

<Card
  title="Create Account"
  icon="user-plus"
  href="https://app.monkei.co/login"
>
  Create your free account on the Monkei Dashboard.
</Card>

## 2. Get your API Key

After logging in, you need an API Key to authenticate your requests.

<Steps>
  <Step title="Access Integrations">
    In the dashboard menu, go to **Integrations**.
  </Step>
  <Step title="Generate Key">
    Click on **API Keys** and then **New API Key**.
  </Step>
  <Step title="Save the Key">
    Copy the generated key. **It will only be shown once!**
  </Step>
</Steps>

<Warning>
  Keep your API Key safe. Never share it or commit it to public repositories.
</Warning>

## 3. Make your first request

Let's create a PIX payment to test the integration.

```bash
curl -X POST https://api.monkei.co/api/v1/transactions/payments/pix \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "amount": 5000,
    "currency": "BRL",
    "expires_in": 1800,
    "description": "My first Monkei payment",
    "request_id": "order_123"
  }'
```

<Note>
  The `amount` field represents the payment amount in the smallest unit (cents). For example, `5000` equals R$ 50,00. The minimum amount is 700 cents (R$ 7,00).
</Note>

You will receive a JSON with the QR Code image to show your customer:

<Info>
  The `qr_code` field contains a base64-encoded PNG image that can be directly displayed in your application. You can use it in an HTML img tag like: `<img src="data:image/png;base64,{qr_code}" />`. The `qr_code_url` field contains the PIX QR code string that payment apps can use to process the payment.
</Info>

## 4. Configure Webhooks

To receive real-time updates (like when the payment is paid), you need to configure a Webhook.

1. Go to **Integrations > Webhooks** in the dashboard.
2. Click **New Webhook**.
3. Enter the URL of your application that will receive the events (e.g., `https://api.yoursite.com/webhooks/monkei`).
4. Select the events you want to listen to (e.g., `PAYMENT_RECEIVED`).
