Create Bitcoin (BTC) payments on the Bitcoin network. Bitcoin is the original cryptocurrency and remains one of the most widely accepted digital currencies.

## Endpoint

```http
POST /api/v1/transactions/payments/btc
```

## Overview

Bitcoin payments are processed on the Bitcoin blockchain, providing a decentralized payment option for your customers.

## Request

<Request>
  <Title>CreateBTCPaymentRequest</Title>
  ```json
  {
    "amount_in_brl": "100.50",
    "expires_in": 3600,
    "description": "Payment in Bitcoin",
    "idempotency_key": "btc_123456789",
    "network": "lightning"
  }
  ```
</Request>

## Parameters

| Field | Type | Required | Values | Description |
|-------|------|----------|--------|-------------|
| `amount_in_brl` | decimal | ✅ | `min=7.00` | Amount in Brazilian Real |
| `expires_in` | integer | ✅ | `min=120` | Expiration in seconds |
| `description` | string | ❌ | - | Payment description |
| `idempotency_key` | string | ✅ | - | Idempotency key |
| `network` | string | ✅ | `"lightning"` | Blockchain network (Lightning Network for payments) |

## Examples

### cURL

```bash
curl -X POST https://api.monkei.co/api/v1/transactions/payments/btc \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk_live_1234567890abcdef" \
  -d '{
    "amount_in_brl": 100.50,
    "expires_in": 3600,
    "description": "Payment in Bitcoin",
    "idempotency_key": "btc_123456789",
    "network": "lightning"
  }'
```

### JavaScript

```javascript
async function createBTCPayment() {
  const response = await fetch('https://api.monkei.co/api/v1/transactions/payments/btc', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'sk_live_1234567890abcdef'
    },
    body: JSON.stringify({
      amount_in_brl: 100.50,
      expires_in: 3600,
      description: 'Payment in Bitcoin',
      idempotency_key: `btc_${Date.now()}`,
      network: 'lightning'
    })
  });

  const payment = await response.json();
  console.log('BTC Amount:', payment.amount_in_crypto);
  console.log('QR Code (Base64):', payment.qr_code);
  console.log('Lightning Invoice (Copy/Paste):', payment.qr_code_url);
  return payment;
}
```

### Python

```python
import requests
import time

def create_btc_payment():
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': 'sk_live_1234567890abcdef'
    }
    
    data = {
        'amount_in_brl': 100.50,
        'expires_in': 3600,
        'description': 'Payment in Bitcoin',
        'idempotency_key': f'btc_{int(time.time())}',
        'network': 'lightning'
    }
    
    response = requests.post(
        'https://api.monkei.co/api/v1/transactions/payments/btc',
        headers=headers,
        json=data
    )
    
    return response.json()
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Transaction ID |
| `amount_in_brl` | decimal | Original amount in BRL |
| `amount_in_crypto` | decimal | Amount in BTC (8 decimals) |
| `platform_fee` | decimal | Platform fee deducted |
| `status` | string | Transaction status |
| `expires_in` | integer | Expiration time in seconds |
| `qr_code` | string | Base64-encoded QR code image that can be directly embedded in HTML |
| `qr_code_url` | string | Lightning invoice string that can be copied and pasted |

## Payment Flow

<Steps>
  <Step title="Create Payment">
    Create a Bitcoin payment specifying the amount in BRL.
  </Step>
  <Step title="Get Lightning Invoice">
    Receive a Lightning Network invoice and QR code.
  </Step>
  <Step title="Customer Pays">
    Customer pays using a Lightning Network compatible wallet.
  </Step>
  <Step title="Confirmation">
    Payment is confirmed instantly on the Lightning Network (no blockchain confirmations needed).
  </Step>
</Steps>

## Important Notes

<Info>
  The amount is automatically converted from BRL to BTC based on current exchange rates. The `amount_in_crypto` field shows the exact BTC amount to receive.
</Info>

<Warning>
  Lightning Network invoices are single-use and time-limited. Each payment requires a new invoice. Expired invoices cannot be used.
</Warning>

## Network Information

- **Network**: Lightning Network (for payments)
- **Address Format**: Lightning invoice
- **Confirmation Time**: Instant (Lightning Network)
- **Transaction Fees**: Paid by the customer (very low on Lightning Network)

## Confirmation Requirements

Bitcoin payments on the Lightning Network are confirmed instantly:

- **Instant Settlement**: Payments are confirmed immediately on the Lightning Network
- **No Block Confirmations**: Lightning Network uses off-chain channels for instant transactions
- **Low Fees**: Transaction fees are minimal compared to on-chain Bitcoin transactions

<Note>
  Lightning Network payments are instant and do not require waiting for blockchain confirmations. This makes Bitcoin payments as fast as traditional payment methods.
</Note>

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `INVALID_NETWORK` | Invalid network | Use "lightning" |
| `AMOUNT_TOO_LOW` | Amount below minimum | Increase to at least R$7.00 |
