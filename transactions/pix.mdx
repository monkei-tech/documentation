Create PIX (Brazilian Instant Payment) transactions and generate QR codes that customers can scan to complete payments instantly.

## Endpoint

```http
POST /api/v1/transactions/payments/pix
```

## Overview

PIX is Brazil's instant payment system that allows real-time transfers 24/7. It's the most popular payment method in Brazil and supports payments in Brazilian Real (BRL).

## Parameters

| Field | Type | Required | Validation | Description |
|-------|------|----------|------------|-------------|
| `amount_in_brl` | decimal | ✅ | `min=7.00` | Amount in Brazilian Real (min: R$7.00) |
| `expires_in` | integer | ✅ | `min=120` | Expiration in seconds (min: 2 minutes) |
| `description` | string | ❌ | - | Payment description |
| `idempotency_key` | string | ✅ | - | Idempotency key to prevent duplicates |
| `customer` | object | ❌ | - | Customer information |

<Info>
  If `customer` is provided, all fields in `metadata` become required.
</Info>

| Code | Description |
|------|-------------|

### JavaScript

```javascript
async function createPixPayment() {
  const response = await fetch('https://api.monkei.co/api/v1/transactions/payments/pix', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'sk_live_1234567890abcdef'
    },
    body: JSON.stringify({
      amount_in_brl: 100.50,
      expires_in: 3600,
      description: 'Payment for product XYZ',
      idempotency_key: `pix_${Date.now()}`,
      customer: {
        customer_id: '12345678901',
        metadata: {
          name: 'John Doe',
          phone: '+5511999999999',
          email: 'john@example.com',
          tax_id: '12345678901'
        }
      }
    })
  });

  const payment = await response.json();
  console.log('QR Code (Base64):', payment.qr_code);
  console.log('QR Code (Copy/Paste):', payment.qr_code_url);
  return payment;
}
```

### Python

```python
import requests
import time

def create_pix_payment():
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': 'sk_live_1234567890abcdef'
    }
    
    data = {
        'amount_in_brl': 100.50,
        'expires_in': 3600,
        'description': 'Payment for product XYZ',
        'idempotency_key': f'pix_{int(time.time())}',
        'customer': {
            'customer_id': '12345678901',
            'metadata': {
                'name': 'John Doe',
                'phone': '+5511999999999',
                'email': 'john@example.com',
                'tax_id': '12345678901'
            }
        }
    }
    
    response = requests.post(
        'https://api.monkei.co/api/v1/transactions/payments/pix',
        headers=headers,
        json=data
    )
    
    return response.json()
```

## QR Code Usage

The response includes two QR code formats:

1. **`qr_code`**: Base64-encoded image that can be directly embedded in HTML
2. **`qr_code_url`**: EMVCo standard QR code string that can be copied and pasted

### Displaying QR Code

```html
<img src="data:image/png;base64,{qr_code}" alt="PIX QR Code" />
```

## Payment Flow

<Steps>
  <Step title="Create Payment">
    Create a PIX payment using the API endpoint.
  </Step>
  <Step title="Display QR Code">
    Show the QR code to your customer (on screen or printed).
  </Step>
  <Step title="Customer Scans">
    Customer scans the QR code with their banking app.
  </Step>
  <Step title="Payment Confirmed">
    Payment is confirmed instantly and you receive a webhook notification.
  </Step>
</Steps>

## Important Notes

<Warning>
  The minimum payment amount is R$7.00. Amounts below this will be rejected.
</Warning>

<Info>
  PIX payments are processed instantly. Once the customer scans and confirms, the payment is settled immediately.
</Info>

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `AMOUNT_TOO_LOW` | Amount below minimum | Increase to at least R$7.00 |
| `INVALID_EXPIRATION` | Expiration too short | Set at least 120 seconds |
