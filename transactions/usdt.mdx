# USDT Payments

Create USDT (Tether) payments on the Polygon network. USDT is a stablecoin pegged to the US Dollar, providing a stable value for crypto payments.

## Endpoint

```http
POST /api/v1/transactions/payments/usdt
```

## Overview

USDT payments are processed on the Polygon network, which offers low transaction fees and fast confirmation times compared to Ethereum mainnet.

## Request

<Request>
  <Title>CreateUSDTPaymentRequest</Title>
  ```json
  {
    "amount_in_brl": 100.50,
    "expires_in": 3600,
    "description": "Payment in cryptocurrency",
    "idempotency_key": "usdt_123456789",
    "network": "polygon"
  }
  ```
</Request>

## Parameters

| Field | Type | Required | Values | Description |
|-------|------|----------|--------|-------------|
| `amount_in_brl` | decimal | ✅ | `min=7.00` | Amount in Brazilian Real |
| `expires_in` | integer | ✅ | `min=120` | Expiration in seconds |
| `description` | string | ❌ | - | Payment description |
| `idempotency_key` | string | ✅ | - | Idempotency key |
| `network` | string | ✅ | `"polygon"` | Blockchain network |

## Examples

### cURL

```bash
curl -X POST https://api.monkei.com/api/v1/transactions/payments/usdt \
  -H "Authorization: Bearer sk_live_1234567890abcdef" \
  -H "Content-Type: application/json" \
  -d '{
    "amount_in_brl": 100.50,
    "expires_in": 3600,
    "description": "Payment in cryptocurrency",
    "idempotency_key": "usdt_123456789",
    "network": "polygon"
  }'
```

### JavaScript

```javascript
async function createUSDTPayment() {
  const response = await fetch('https://api.monkei.com/api/v1/transactions/payments/usdt', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer sk_live_1234567890abcdef',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      amount_in_brl: 100.50,
      expires_in: 3600,
      description: 'Payment in cryptocurrency',
      idempotency_key: `usdt_${Date.now()}`,
      network: 'polygon'
    })
  });

  const payment = await response.json();
  console.log('USDT Amount:', payment.amount_in_crypto);
  console.log('Payment Address:', payment.address);
  return payment;
}
```

### Python

```python
import requests
import time

def create_usdt_payment():
    headers = {
        'Authorization': 'Bearer sk_live_1234567890abcdef',
        'Content-Type': 'application/json'
    }
    
    data = {
        'amount_in_brl': 100.50,
        'expires_in': 3600,
        'description': 'Payment in cryptocurrency',
        'idempotency_key': f'usdt_{int(time.time())}',
        'network': 'polygon'
    }
    
    response = requests.post(
        'https://api.monkei.com/api/v1/transactions/payments/usdt',
        headers=headers,
        json=data
    )
    
    return response.json()
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Transaction ID |
| `amount_in_brl` | decimal | Original amount in BRL |
| `amount_in_crypto` | decimal | Amount in USDT (6 decimals) |
| `platform_fee` | decimal | Platform fee deducted |
| `status` | string | Transaction status |
| `expires_in` | integer | Expiration time in seconds |
| `qr_code` | string | QR code with payment address |
| `qr_code_url` | string | QR code image URL |
| `address` | string | Polygon wallet address for payment |

## Payment Flow

<Steps>
  <Step title="Create Payment">
    Create a USDT payment specifying the amount in BRL.
  </Step>
  <Step title="Get Address">
    Receive a Polygon wallet address and QR code.
  </Step>
  <Step title="Customer Pays">
    Customer sends USDT to the provided address.
  </Step>
  <Step title="Confirmation">
    Payment is confirmed once the transaction is verified on Polygon network.
  </Step>
</Steps>

## Important Notes

<Info>
  The amount is automatically converted from BRL to USDT based on current exchange rates. The `amount_in_crypto` field shows the exact USDT amount to receive.
</Info>

<Warning>
  Payments must be sent to the exact address provided. Sending to a different address will result in payment loss.
</Warning>

## Network Information

- **Network**: Polygon (MATIC)
- **Token Contract**: USDT ERC-20 on Polygon
- **Confirmation Time**: Generally 2 confirmations, 1-3 seconds on-chain
- **Transaction Fees**: Paid by the customer (very low on Polygon)

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `INVALID_NETWORK` | Invalid network | Use "polygon" |
| `AMOUNT_TOO_LOW` | Amount below minimum | Increase to at least R$7.00 |
