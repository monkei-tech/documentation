Create USDT (Tether) payments on the Polygon network. USDT is a stablecoin pegged to the US Dollar, providing a stable value for crypto payments.

## Endpoint

```http
POST /api/v1/transactions/payments/usdt
```

## Overview

USDT payments are processed on the Polygon network, which offers low transaction fees and fast confirmation times compared to Ethereum mainnet.

## Request

<Request>
  <Title>CreateUSDTPaymentRequest</Title>
  ```json
  {
    "amount": 2050,
    "currency": "BRL",
    "expires_in": 1800,
    "description": "Payment for services",
    "request_id": "usdt_1234343423432342342344343442345234643789",
    "network": "polygon"
  }
  ```
</Request>

<Info>
  **Amount**: The `amount` field represents the fiat currency amount that will be charged, specified in the smallest unit (cents). For example, `2050` represents R$ 20.50 when currency is BRL or $20.50 when currency is USD.
</Info>

<Info>
  **Currency**: The `currency` field specifies the conversion currency. Currently supported: `BRL` (Brazilian Real) and `USD` (US Dollar). We plan to expand support for more currencies in the future.
</Info>

<Info>
  **Request ID**: The `request_id` is a client-side identification ID that guarantees idempotency and will be sent via transaction webhook as `request_id`. This allows you to correlate webhook events with your original payment requests. Use a unique identifier for each payment request (e.g., UUID, timestamp-based ID, or your internal order ID). If you send the same `request_id` multiple times, the system will return the same transaction instead of creating duplicates.
</Info>

## Parameters

| Field | Type | Required | Values | Description |
|-------|------|----------|--------|-------------|
| `amount` | integer | ✅ | `min=700` | Payment amount in smallest unit (cents for BRL/USD). Example: `2050` = R$ 20.50 or $20.50 |
| `currency` | string | ✅ | `"BRL"`, `"USD"` | Conversion currency. Currently supports BRL and USD, with more currencies planned for the future |
| `expires_in` | integer | ✅ | `min=120, max=1800` | Expiration time in seconds (minimum 120 seconds, maximum 1800 seconds / 30 minutes) |
| `description` | string | ❌ | `max=100` | Payment description |
| `request_id` | string | ✅ | `max=100` | Client-side identification ID that will be sent via transaction webhook as `request_id` |
| `network` | string | ✅ | `"polygon"` | Blockchain network |

### JavaScript

```javascript
async function createUSDTPayment() {
  const response = await fetch('https://api.monkei.co/api/v1/transactions/payments/usdt', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'sk_live_1234567890abcdef'
    },
    body: JSON.stringify({
      amount: 2050, // R$ 20.50 in cents
      currency: 'BRL',
      expires_in: 1800,
      description: 'Payment for services',
      request_id: `usdt_${Date.now()}`,
      network: 'polygon'
    })
  });

  const result = await response.json();
  if (result.success) {
    console.log('Transaction ID:', result.data.id);
    console.log('Fiat Amount:', result.data.fiat_amount); // 2050 (cents)
    console.log('Crypto Amount (micro-USDT):', result.data.crypto_amount); // 4180000 (smallest unit)
    console.log('Crypto Amount (USDT):', result.data.crypto_amount / 1000000); // Convert micro-USDT to USDT
    console.log('QR Code (Base64):', result.data.qr_code);
  }
  return result;
}
```

### Python

```python
import requests
import time

def create_usdt_payment():
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': 'sk_live_1234567890abcdef'
    }
    
    data = {
        'amount': 2050,  # R$ 20.50 in cents
        'currency': 'BRL',
        'expires_in': 1800,
        'description': 'Payment for services',
        'request_id': f'usdt_{int(time.time())}',
        'network': 'polygon'
    }
    
    response = requests.post(
        'https://api.monkei.co/api/v1/transactions/payments/usdt',
        headers=headers,
        json=data
    )
    
    result = response.json()
    if result.get('success'):
        print(f"Transaction ID: {result['data']['id']}")
        print(f"Fiat Amount: {result['data']['fiat_amount']}")  # 2050 (cents)
        print(f"Crypto Amount (micro-USDT): {result['data']['crypto_amount']}")  # 4180000 (smallest unit)
        print(f"Crypto Amount (USDT): {result['data']['crypto_amount'] / 1000000}")  # Convert micro-USDT to USDT
    
    return result
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | object | Response data object |
| `data.id` | string | Transaction ID |
| `data.status` | string | Transaction status (PENDING, CONFIRMED, etc.) |
| `data.expires_in` | integer | Expiration time in seconds |
| `data.fiat_amount` | integer | Payment amount in fiat currency (smallest unit, e.g., cents for BRL/USD) |
| `data.crypto_amount` | integer | Amount in USDT (smallest unit, 6 decimals - micro-USDT) |
| `data.qr_code` | string | Base64-encoded QR code image that can be directly embedded in HTML |
| `data.qr_code_url` | string | Payment address string that can be copied and pasted |
| `message` | string | Response message |

## Crypto Amount Calculation

<Info>
  **How `crypto_amount` is calculated:**
  
  The `crypto_amount` field represents the USDT amount in the smallest unit (micro-USDT), which uses 10^6 (1,000,000) as the multiplier.
  
  **Calculation process:**
  1. The system receives the `amount` in fiat currency (smallest unit, e.g., cents for BRL/USD)
  2. It fetches the current exchange rate (e.g., how many BRL per 1 USDT)
  3. It converts: `(fiat_amount_in_cents / 100) / exchange_rate = crypto_amount (in USDT)`
  4. It multiplies by 10^6 to get the smallest unit: `crypto_amount * 1,000,000 = crypto_amount (micro-USDT)`
  
  **Example:**
  - Input: `amount: 2050` (R$ 20.50 in cents), `currency: "BRL"`
  - Exchange rate: 1 USDT = 4.90 BRL (example - quantos BRL por 1 USDT)
  - First convert cents to BRL: `2050 / 100 = 20.50 BRL`
  - Then divide by exchange rate: `20.50 BRL / 4.90 BRL/USDT = 4.18 USDT`
  - Convert to smallest unit: `4.18 * 1,000,000 = 4,180,000 micro-USDT`
  - Response: `crypto_amount: 4180000`
  
  **To convert back to USDT:**
  - Divide by 10^6: `4180000 / 1,000,000 = 4.18 USDT`
  
  **Note:** The exchange rate represents how many BRL you need to buy 1 USDT (e.g., 1 USDT = X BRL). The calculation is: `(fiat_amount_in_cents / 100) / exchange_rate * 1,000,000 = crypto_amount_in_micro_usdt`. The actual value depends on the current exchange rate at the time of the request.
</Info>

## Important Notes

<Info>
  The `amount` field represents the fiat currency amount that will be charged, specified in the smallest unit. The system automatically converts this amount to USDT based on current exchange rates. The `crypto_amount` field in the response shows the exact USDT amount to receive (in smallest unit, 6 decimals - micro-USDT).
</Info>

<Info>
  The `currency` field specifies the conversion currency. Currently, we support `BRL` (Brazilian Real) and `USD` (US Dollar). We plan to expand support for more currencies in the future.
</Info>

<Info>

This allows you to correlate webhook events with your original payment requests. Make sure to use a unique identifier for each payment request. ## Network Information

- **Network**: Polygon (MATIC)
- **Token Contract**: USDT ERC-20 on Polygon
- **Confirmation Time**: Generally 2 confirmations, 1-3 seconds on-chain
- **Transaction Fees**: Paid by the customer (very low on Polygon)

## Error Handling

### Common Errors

| Code | Description | Solution |
|------|-------------|----------|
| `VALIDATION_ERROR` | Invalid field | Check the parameters sent |
| `INVALID_NETWORK` | Invalid network | Use "polygon" |
| `VALIDATION_ERROR` | Invalid field value | Check field 'amount' must be at least 700 (R$ 7.00 or $7.00) |
