# Health Overview

The Health API allows you to monitor the system status and verify that the Monkei API is operational and responding to requests.

## What is Health Check?

Health checks provide a simple way to verify that the Monkei API is operational. This is essential for monitoring systems, load balancers, and automated health checks.

<Note>
  Health checks are public endpoints that don't require authentication. They're designed to be lightweight and fast, returning a simple response.
</Note>

## Use Cases

- **System Monitoring**: Check API availability before making requests
- **Load Balancer Health Checks**: Configure load balancers to route traffic based on health status
- **Uptime Monitoring**: Set up monitoring systems to alert when the API is down
- **CI/CD Pipelines**: Verify API health in deployment pipelines

## Getting Started

<Steps>
  <Step title="Check System Health">
    Use the <a href="/health/health">Health Check</a> endpoint to verify the API is operational.
