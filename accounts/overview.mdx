# Accounts Overview

The Accounts API allows you to query detailed information about your account, including balances by ledger type, account status, and configured payment methods.

## What is an Account?

Your Monkei account represents your business or personal account in the platform. It holds your balances, tracks transactions, and manages your payment settings.

<Note>
  Account balance endpoints are available for both public API and internal dashboard. The API version has more restricted authentication while the dashboard allows greater flexibility.
</Note>

## Supported Ledger Types

| Ledger Type | Description | Currency |
|-------------|-------------|----------|
| `BRL_AVAILABLE` | Brazilian Real balance | BRL |
| `USDT_AVAILABLE` | USDT balance | USD |
| `BTC_AVAILABLE` | Bitcoin balance | USD |

## Balance Information

Each ledger provides three balance values:

- **Total**: Complete balance in the ledger
- **Available**: Balance available for use (withdrawals, payments)
- **Hold**: Balance blocked or pending (pending transactions, holds)

## Use Cases

- **Balance Monitoring**: Check available funds before creating payments or withdrawals
- **Financial Reporting**: Track balances across different currencies
- **Transaction Planning**: Verify sufficient balance for operations
- **Account Management**: Monitor account status and health

## Getting Started

<Steps>
  <Step title="Check Balance">
    Use the <a href="/balance">Account Balance</a> endpoint to query your current balances.
  </Step>
  <Step title="Force Refresh">
    Use the `refresh=true` parameter to get real-time balance data, bypassing cache.
  </Step>
  <Step title="Monitor Changes">
    Balance updates automatically as transactions are processed. Use webhooks for real-time notifications.
  </Step>
</Steps>
