# Quotes

A API de Quotes fornece acesso a cotações em tempo real de criptomoedas em relação às moedas fiduciárias. As cotações são atualizadas continuamente e incluem informações de volume, variação e tempo de expiração.

## Visão Geral

<Note>
  As cotações possuem tempo de expiração configurável e indicadores de proximidade de expiração para garantir precisão nos valores de conversão.
</Note>

## Endpoints

### Consultar Última Cotação
Busca a cotação mais recente de uma criptomoeda em relação a uma moeda fiduciária.

```http
POST /api/v1/quotes/latest
```

#### Request

<Request>
  <Title>FindLatestQuoteRequest</Title>
  ```json
  {
    "fiat_currency": "BRL",
    "crypto_currency": "USDT"
  }
  ```
</Request>

#### Parâmetros

| Campo | Tipo | Obrigatório | Descrição | Valores |
|-------|------|-------------|-----------|---------|
| `fiat_currency` | string | ✅ | Moeda fiduciária de referência | `"BRL"`, `"USD"` |
| `crypto_currency` | string | ✅ | Criptomoeda para cotação | `"BTC"`, `"ETH"`, `"USDT"` |

#### Pares Suportados

| Fiat | Crypto | Par | Exemplo |
|------|--------|-----|---------|
| BRL | BTC | BTCBRL | Bitcoin em Reais |
| BRL | ETH | ETHBRL | Ethereum em Reais |
| BRL | USDT | USDTBRL | Tether em Reais |
| USD | BTC | BTCUSD | Bitcoin em Dólares |
| USD | ETH | ETHUSD | Ethereum em Dólares |
| USD | USDT | USDTUSD | Tether em Dólares |

<Info>
  O sistema automaticamente determina o par de moedas (symbol) baseado nas moedas informadas.
</Info>

#### Response

<Response>


#### Campos de Resposta

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `id` | string | UUID único da cotação |
| `symbol` | string | Par de moedas (ex: "BTCBRL") |
| `exchange_rate` | decimal | Taxa de câmbio atual |
| `source` | string | Fonte da cotação |
| `exchange_rate_source` | string | Fonte específica da taxa |
| `fiat_currency` | string | Moeda fiduciária |
| `crypto_currency` | string | Criptomoeda |
| `decimal_factor` | decimal | Fator decimal para precisão |
| `consulted_at` | datetime | Timestamp da consulta |
| `expires_at` | datetime | Timestamp de expiração |
| `variation` | decimal | Variação percentual |
| `icon` | string | URL do ícone da criptomoeda |
| `market` | string | Identificador do mercado |
| `volume_usd` | decimal | Volume em USD (24h) |
| `volume_brl` | decimal | Volume em BRL (24h) |
| `created_at` | datetime | Timestamp de criação |
| `updated_at` | datetime | Timestamp de atualização |
| `time_until_expiration` | integer | Segundos até expirar |
| `is_expired` | boolean | Cotação expirada |
| `is_expiring_soon` | boolean | Expirando em breve |

#### Status Codes

| Código | Descrição |
|--------|-----------|
| `200` | Cotação encontrada com sucesso |
| `400` | Requisição inválida (par não suportado) |
| `404` | Cotação não encontrada para o par |
| `500` | Erro interno do servidor |

## Lógica de Expiração

<Info>
  As cotações possuem tempo de vida configurável para garantir precisão nos valores de conversão.
</Info>

### Tempos de Expiração

| Estado | Tempo Restante | Descrição |
|--------|----------------|-----------|
| **Válida** | > 10 minutos | Cotação plenamente válida |
| **Expirando** | 2-10 minutos | `is_expiring_soon: true` |
| **Expirada** | < 2 minutos | `is_expired: true` |

### Indicadores

```json
{
  "time_until_expiration": 1800,
  "is_expired": false,
  "is_expiring_soon": false
}
```

## Fontes de Cotação

O sistema agrega dados de múltiplas fontes:

| Fonte | Descrição | Prioridade |
|-------|-----------|------------|
| `BRASIL_BITCOIN` | Exchange brasileira | Alta |
| `BINANCE` | Exchange global | Alta |
| `COINBASE` | Exchange americana | Média |
| `COINGECKO` | Agregador de preços | Baixa |

<Info>
  As fontes são combinadas usando algoritmos de média ponderada para garantir precisão e liquidez.
</Info>

### JavaScript - Múltiplas Cotações

```javascript
async function getQuotes(pairs) {
  const headers = {
    'Authorization': 'Bearer sk_live_1234567890abcdef',
    'Content-Type': 'application/json'
  };

  const quotes = await Promise.all(
    pairs.map(async ([fiat, crypto]) => {
      const response = await fetch(
        'https://api.monkei.com/api/v1/quotes/latest',
        {
          method: 'POST',
          headers,
          body: JSON.stringify({
            fiat_currency: fiat,
            crypto_currency: crypto
          })
        }
      );

      return response.json();
    })
  );

  return quotes;
}

// Buscar múltiplas cotações
const quotes = await getQuotes([
  ['BRL', 'BTC'],
  ['BRL', 'ETH'],
  ['USD', 'USDT']
]);

quotes.forEach(({ quote }) => {
  console.log(`${quote.symbol}: ${quote.exchange_rate}`);
  console.log(`Expira em: ${quote.time_until_expiration}s`);
  console.log(`Variação: ${quote.variation}%`);
  console.log('---');
});
```

### Python - Monitoramento de Cotações

```python
import requests
import time
from datetime import datetime

class QuoteMonitor:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://api.monkei.com/api/v1/quotes/latest"
        self.headers = {
            'Authorization': f'Bearer {api_key}',
            'Content-Type': 'application/json'
        }

    def get_quote(self, fiat, crypto):
        """Busca cotação atual"""
        response = requests.post(
            self.base_url,
            headers=self.headers,
            json={
                'fiat_currency': fiat,
                'crypto_currency': crypto
            }
        )

        if response.status_code == 200:
            data = response.json()
            return data['quote']
        else:
            raise Exception(f'Erro ao buscar cotação: {response.status_code}')

    def monitor_quote(self, fiat, crypto, callback=None):
        """Monitora cotação com callback para atualizações"""
        print(f"Iniciando monitoramento de {crypto}/{fiat}")

        while True:
            try:
                quote = self.get_quote(fiat, crypto)

                status = "VÁLIDA"
                if quote['is_expired']:
                    status = "EXPIRADA ⚠️"
                elif quote['is_expiring_soon']:
                    status = "EXPIRANDO SOON ⏰"

                print(f"{datetime.now()}: {quote['symbol']} - {quote['exchange_rate']} ({status})")

                if callback:
                    callback(quote)

                # Espera baseada no tempo de expiração
                if quote['is_expired']:
                    time.sleep(30)  # Cotação expirada, consulta mais rápido
                elif quote['is_expiring_soon']:
                    time.sleep(60)  # Expirando, consulta frequente
                else:
                    time.sleep(300)  # Válida, consulta menos frequente

            except Exception as e:
                print(f"Erro: {e}")
                time.sleep(60)

# Uso
monitor = QuoteMonitor("sk_live_1234567890abcdef")

def quote_callback(quote):
    """Callback chamado a cada atualização"""
    if abs(quote['variation']) > 5.0:  # Variação > 5%
        print(f"🚨 Variação significativa: {quote['variation']}%")

# Iniciar monitoramento
monitor.monitor_quote('BRL', 'BTC', callback=quote_callback)
```

### Go - Verificador de Expiração

```go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
    "time"
)

type QuoteRequest struct {
    FiatCurrency   string `json:"fiat_currency"`
    CryptoCurrency string `json:"crypto_currency"`
}

type QuoteResponse struct {
    Quote Quote `json:"quote"`
}

type Quote struct {
    ID                 string    `json:"id"`
    Symbol             string    `json:"symbol"`
    ExchangeRate       float64   `json:"exchange_rate"`
    TimeUntilExpiration int64    `json:"time_until_expiration"`
    IsExpired          bool      `json:"is_expired"`
    IsExpiringSoon     bool      `json:"is_expiring_soon"`
    ConsultedAt        time.Time `json:"consulted_at"`
    ExpiresAt          time.Time `json:"expires_at"`
    Variation          float64   `json:"variation"`
}

func getQuote(apiKey, fiat, crypto string) (*Quote, error) {
    reqBody := QuoteRequest{
        FiatCurrency:   fiat,
        CryptoCurrency: crypto,
    }

    jsonData, _ := json.Marshal(reqBody)

    req, _ := http.NewRequest("POST", "https://api.monkei.com/api/v1/quotes/latest", bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer "+apiKey)
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()

    var quoteResp QuoteResponse
    if err := json.NewDecoder(resp.Body).Decode(&quoteResp); err != nil {
        return nil, err
    }

    return &quoteResp.Quote, nil
}

func main() {
    apiKey := "sk_live_1234567890abcdef"

    for {
        quote, err := getQuote(apiKey, "BRL", "USDT")
        if err != nil {
            fmt.Printf("Erro: %v\n", err)
            time.Sleep(time.Minute)
            continue
        }

        status := "VÁLIDA ✅"
        switch {
        case quote.IsExpired:
            status = "EXPIRADA ❌"
        case quote.IsExpiringSoon:
            status = "EXPIRANDO ⏰"
        }

        fmt.Printf("USDT/BRL: %.6f | Status: %s | Variação: %.2f%%\n",
            quote.ExchangeRate, status, quote.Variation)
        fmt.Printf("Expira em: %v (%ds restantes)\n",
            quote.ExpiresAt.Format("15:04:05"),
            quote.TimeUntilExpiration)

        // Próxima consulta baseada no status
        var waitTime time.Duration
        switch {
        case quote.IsExpired:
            waitTime = 30 * time.Second
        case quote.IsExpiringSoon:
            waitTime = 2 * time.Minute
        default:
            waitTime = 10 * time.Minute
        }

        time.Sleep(waitTime)
    }
}
```

## Tratamento de Erros

### Estrutura de Erro

```json
{
  "error": "UNSUPPORTED_PAIR",
  "message": "O par de moedas LTC/BRL não é suportado",
  "details": "Supported pairs: BTC/BRL, ETH/BRL, USDT/BRL, BTC/USD, ETH/USD, USDT/USD",
  "code": 400,
  "operation": "quote.FindLatestQuote"
}
```

### Erros Comuns

| Código | Descrição | Solução |
|--------|-----------|---------|
| `UNSUPPORTED_PAIR` | Par de moedas não suportado | Use um dos pares disponíveis |
| `QUOTE_NOT_FOUND` | Cotação não encontrada | Tente novamente mais tarde |
| `SERVICE_UNAVAILABLE` | Fonte de cotação indisponível | Verifique status da API |
| `RATE_LIMIT_EXCEEDED` | Rate limit excedido | Reduza frequência de consultas |

## Melhores Práticas

### Cache Local

Implemente cache local para evitar consultas excessivas:

```javascript
class QuoteCache {
  constructor(ttlMinutes = 5) {
    this.cache = new Map();
    this.ttl = ttlMinutes * 60 * 1000;
  }

  get(key) {
    const cached = this.cache.get(key);
    if (cached && Date.now() - cached.timestamp < this.ttl) {
      return cached.data;
    }
    return null;
  }

  set(key, data) {
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    });
  }
}

const quoteCache = new QuoteCache(5); // Cache de 5 minutos
```

### Refresh Inteligente

Atualize cotações baseado no tempo de expiração:

```javascript
function shouldRefresh(quote) {
  if (quote.is_expired) return true;        // Expirada: atualizar imediatamente
  if (quote.is_expiring_soon) return true;  // Expirando: atualizar em breve
  return false;                             // Válida: manter cache
}
```

### Fallback de Fontes

Em caso de falha da fonte principal:

```javascript
async function getQuoteWithFallback(fiat, crypto) {
  try {
    // Tentar fonte primária
    return await getQuote(fiat, crypto);
  } catch (error) {
    console.warn('Fonte primária falhou, tentando fallback:', error.message);

    // Implementar lógica de fallback
    // 1. Tentar cache antigo se disponível
    // 2. Usar fonte secundária
    // 3. Retornar erro genérico se todas falharem
    throw error;
  }
}
```
