---
title: "Latest Exchange Rate"
openapi: "POST /api/v1/exchange/latest"
description: "Retrieve the latest exchange rate quote for a fiat and cryptocurrency pair"
---

Retrieve the latest valid exchange rate quote for a specific fiat currency and cryptocurrency pair, including expiration information and market data.

## Endpoint

```http
POST /api/v1/exchange/latest
```

## Request Body

<ParamField body="fiat_currency" type="string" required>
  The fiat currency code (e.g., `BRL`).
</ParamField>

<ParamField body="crypto_currency" type="string" required>
  The cryptocurrency code (e.g., `BTC`, `USDT`).
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.monkei.co/api/v1/exchange/latest \
  --header 'Content-Type: application/json' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --data '{
  "fiat_currency": "BRL",
  "crypto_currency": "BTC"
}'
```

```javascript JavaScript
const options = {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
    fiat_currency: 'BRL',
    crypto_currency: 'BTC'
  })
};

fetch('https://api.monkei.co/api/v1/exchange/latest', options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

</RequestExample>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `quote` | object | Quote information object |

### Quote Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique quote identifier |
| `symbol` | string | Quote symbol (e.g., "BTC", "USDT") |
| `exchange_rate` | string | Current exchange rate |
| `source` | string | Quote source (e.g., "SYSTEM") |
| `exchange_rate_source` | string | Exchange rate provider (e.g., "FOXBIT", "BRASIL_BITCOIN") |
| `fiat_currency` | string | Fiat currency code (e.g., "BRL") |
| `crypto_currency` | string | Cryptocurrency code (e.g., "BTC", "USDT") |
| `decimal_factor` | string | Decimal precision factor |
| `consulted_at` | string (ISO 8601) | Timestamp when the quote was consulted |
| `expires_at` | string (ISO 8601) | Timestamp when the quote expires |
| `variation` | string | Price variation percentage (can be negative) |
| `icon` | string | Icon identifier or URL |
| `market` | string | Market identifier |
| `volume_usd` | string | Trading volume in USD |
| `volume_brl` | string | Trading volume in BRL |
| `created_at` | string (ISO 8601) | Quote creation timestamp |
| `updated_at` | string (ISO 8601) | Quote last update timestamp |
| `time_until_expiration` | integer | Seconds remaining until expiration |
| `is_expired` | boolean | Whether the quote has expired |
| `is_expiring_soon` | boolean | Whether the quote is expiring soon |

<Note>
  The `exchange_rate` value represents how many units of the fiat currency are needed to buy one unit of the cryptocurrency. For example, if `exchange_rate` is "471496" for BTC/BRL, it means 1 BTC costs 471,496 BRL.
</Note>

<Note>
  The `variation` field shows the percentage change in price. A negative value indicates a price decrease, while a positive value indicates a price increase.
</Note>

<Note>
  Quotes have an expiration time. Use `is_expired` and `time_until_expiration` to check if a quote is still valid before using it in transactions.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Quote retrieved successfully |
| `400` | Bad request - invalid parameters or missing required fields |
| `401` | Unauthorized - invalid or missing API key |
| `404` | Not found - no quote available for the specified currency pair |
| `500` | Internal server error |


<Warning>
  Always check the `is_expired` and `time_until_expiration` fields before using a quote in transactions. Using an expired quote may result in incorrect conversions or transaction failures.
</Warning>

<Note>
  Exchange rates are updated every 30 seconds. The `expires_at` field indicates when the quote becomes invalid. Quotes typically expire after 15 minutes, but this may vary.
</Note>

<Note>
  The `exchange_rate` and other numeric fields are returned as strings to maintain precision. When performing calculations, parse them as decimal numbers using appropriate libraries to avoid floating-point precision issues.
</Note>
