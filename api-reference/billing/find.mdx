---
title: "Find Billing"
openapi: "GET /api/v1/bills/{billingId}"
description: "Retrieve a specific billing by its ID"
---

Retrieve detailed information about a specific billing by its unique identifier.

## Endpoint

```http
GET /api/v1/bills/{billingId}
```

## Path Parameters

<ParamField path="billingId" type="string" required>
  The unique identifier (UUID) of the billing to retrieve.
</ParamField>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique billing identifier |
| `frequency` | string | Billing frequency: `ONE_TIME` or `MULTIPLE_PAYMENTS` |
| `status` | string | Current billing status |
| `url` | string | Payment URL for the customer |
| `amount` | string | Total billing amount |
| `allow_coupon` | boolean | Whether coupons are allowed |
| `coupons_codes` | array | List of applied coupon codes |
| `payment_methods` | array | Available payment methods |
| `customer` | object | Customer information (if provided) |
| `products` | array | List of products in the billing |
| `completion_url` | string | URL to redirect after payment completion |
| `return_url` | string | URL to redirect when user clicks back |

### Customer Object

| Field | Type | Description |
|-------|------|-------------|
| `customer_id` | string | Customer ID (if existing customer) |
| `customer_metadata` | object | Customer details (name, phone, email, tax_id) |

### Products Array

Each product object contains:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Product identifier |
| `external_id` | string | External product ID from your system |
| `price` | integer | Product price in smallest unit (cents) |
| `quantity` | integer | Product quantity |
