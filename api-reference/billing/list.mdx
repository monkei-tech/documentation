---
title: "List Billings"
openapi: "GET /api/v1/bills"
description: "Retrieve a paginated list of billings with optional filtering"
---

Retrieve a paginated list of all billings for your account with optional filtering by status and frequency.

## Endpoint

```http
GET /api/v1/bills
```

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination. Minimum value: 1.
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Number of items per page. Minimum value: 1, Maximum value: 100.
</ParamField>

<ParamField query="status" type="string">
  Filter billings by status.
  Allowed values: `PAID`, `ACTIVE`, `FAILED`, `CANCELED`.
</ParamField>

<ParamField query="frequency" type="string">
  Filter billings by frequency.
  Allowed values: `ONE_TIME`, `MULTIPLE_PAYMENTS`.
</ParamField>

## Response Structure

The response follows the standard pagination format:

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Indicates if the request was successful |
| `data` | object | Contains the billings array and pagination info |
| `data.data` | array | Array of billing objects |
| `data.pagination` | object | Pagination metadata |
| `message` | string | Success message |

### Pagination Object

| Field | Type | Description |
|-------|------|-------------|
| `page` | integer | Current page number |
| `limit` | integer | Number of items per page |
| `total` | integer | Total number of billings |
| `total_pages` | integer | Total number of pages |

### Billing Object

Each billing in the array contains:

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique billing identifier |
| `frequency` | string | Billing frequency: `ONE_TIME` or `MULTIPLE_PAYMENTS` |
| `status` | string | Current billing status |
| `url` | string | Payment URL (only for `MULTIPLE_PAYMENTS` or when available) |
| `amount` | integer | Total billing amount in smallest unit (cents) |
| `allow_coupon` | boolean | Whether coupons are allowed |
| `coupons_codes` | array | List of applied coupon codes |
| `payment_methods` | array | Available payment methods |
| `currency` | string | Currency code (`BRL` or `USD`) |
| `idiom` | string | Language/idiom (`pt-BR` or `en-US`) |
| `customer` | object \| null | Customer information (if provided) |
| `products` | array | List of products in the billing |
| `completion_url` | string | URL to redirect after payment completion |
| `return_url` | string | URL to redirect when user clicks back |

<Note>
  The `customer` field will be `null` or omitted if the billing was created with `frequency: MULTIPLE_PAYMENTS` and no customer data was provided.
</Note>

<Note>
  The `url` field is only present for billings with `frequency: MULTIPLE_PAYMENTS` or when a payment URL has been generated.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Billings retrieved successfully |
| `400` | Bad request - invalid query parameters |
| `401` | Unauthorized - invalid or missing API key |
| `500` | Internal server error |

## Examples

### Basic Request

```javascript
async function listBillings(apiKey) {
  const response = await fetch(
    'https://api.monkei.co/api/v1/bills?page=1&limit=10',
    {
      method: 'GET',
      headers: {
        'X-API-Key': apiKey
      }
    }
  );

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to list billings');
  }

  const data = await response.json();
  return data.data;
}

// Usage
const result = await listBillings('YOUR_API_KEY');
console.log('Billings:', result.data);
console.log('Total:', result.pagination.total);
```

### Python Example

```python
import requests

def list_billings(api_key, page=1, limit=10, status=None, frequency=None):
    url = "https://api.monkei.co/api/v1/bills"
    headers = {
        'X-API-Key': api_key
    }
    params = {
        'page': page,
        'limit': limit
    }
    
    if status:
        params['status'] = status
    if frequency:
        params['frequency'] = frequency
    
    response = requests.get(url, headers=headers, params=params)
    response.raise_for_status()
    
    data = response.json()
    return data['data']

# Usage
result = list_billings('YOUR_API_KEY', page=1, limit=10, status='ACTIVE')
print(f"Found {len(result['data'])} billings")
print(f"Total: {result['pagination']['total']}")
```

## Use Cases

### Paginate Through All Billings

```javascript
async function getAllBillings(apiKey) {
  let allBillings = [];
  let page = 1;
  let hasMore = true;

  while (hasMore) {
    const response = await fetch(
      `https://api.monkei.co/api/v1/bills?page=${page}&limit=100`,
      {
        method: 'GET',
        headers: {
          'X-API-Key': apiKey
        }
      }
    );

    const data = await response.json();
    const result = data.data;

    allBillings = allBillings.concat(result.data);

    hasMore = page < result.pagination.total_pages;
    page++;
  }

  return allBillings;
}
```

### Get Billings Summary

```javascript
async function getBillingsSummary(apiKey) {
  const response = await fetch(
    'https://api.monkei.co/api/v1/bills?page=1&limit=1',
    {
      method: 'GET',
      headers: {
        'X-API-Key': apiKey
      }
    }
  );

  const data = await response.json();
  const pagination = data.data.pagination;

  return {
    total: pagination.total,
    totalPages: pagination.total_pages,
    pageSize: pagination.limit
  };
}
```
