<ParamField body="amount" type="integer" required>
  Payment amount in smallest unit (cents for BRL/USD). Minimum: 700 cents (R$ 7.00 or $7.00).
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code for the payment.
  Allowed values: `BRL`, `USD`.
</ParamField>

<ParamField body="expires_in" type="integer" required>
  Expiration time in seconds. Minimum: 120 seconds (2 minutes), Maximum: 172800 seconds (48 hours).
</ParamField>

<ParamField body="description" type="string">
  Payment description (optional, max 255 characters).
</ParamField>

<ParamField body="request_id" type="string" required>
  Unique key to prevent duplicate payments. This key is a correlation identifier between your transaction and Monkei's transaction. It will be sent back in the webhook and guarantees idempotency - using the same `request_id` will return the same payment.
</ParamField>

<ParamField body="customer" type="object">
  Customer information (optional). If provided, all metadata fields are required.
  
  <Expandable title="properties">
    <ParamField body="customer_id" type="string">
      Existing customer ID (optional).
    </ParamField>
    <ParamField body="metadata" type="object" required>
      Customer metadata (required if customer is provided).
      <Expandable title="properties">
        <ParamField body="name" type="string" required>Customer name.</ParamField>
        <ParamField body="phone" type="string" required>Customer phone number.</ParamField>
        <ParamField body="email" type="string" required>Customer email address.</ParamField>
        <ParamField body="tax_id" type="string" required>Customer tax ID (CPF/CNPJ).</ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique payment transaction identifier |
| `fiat_amount` | integer | Payment amount in fiat currency (smallest unit - cents) |
| `status` | string | Payment status: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELED` |
| `expires_in` | integer | Expiration time in seconds |
| `qr_code` | string | QR code image in base64 format (for display) |
| `qr_code_url` | string | PIX QR code string (for payment apps) |

<Note>
  The `qr_code` field contains a base64-encoded image that can be directly displayed in your application. The `qr_code_url` field contains the PIX QR code string that can be used by payment applications to process the payment.
</Note>

<Note>
  The `customer` field is optional. If you don't provide customer information, the payment can still be created, but customer data won't be associated with the transaction.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | PIX QR code created successfully |
| `400` | Bad request - invalid parameters or validation error |
| `401` | Unauthorized - invalid or missing API key |
| `500` | Internal server error |

### Python Example

```python
import requests
import time

def create_pix_payment(api_key, amount, expires_in, customer=None):
    url = "https://api.monkei.co/api/v1/transactions/payments/pix"
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': api_key
    }
    
    payload = {
        'amount': amount,
        'currency': 'BRL',
        'expires_in': expires_in,
        'description': 'Payment for services',
        'request_id': f'pix_{int(time.time())}'
    }
    
    if customer:
        payload['customer'] = {
            'customer_id': customer.get('id'),
            'metadata': {
                'name': customer['name'],
                'phone': customer['phone'],
                'email': customer['email'],
                'tax_id': customer['tax_id']
            }
        }
    
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    
    data = response.json()
    return data['data']

# Usage
payment = create_pix_payment(
    'YOUR_API_KEY',
    '200.2',
    3600,
    {
        'id': '12345678901',
        'name': 'John Doe',
        'phone': '5511999999999',
        'email': 'customer@example.com',
        'tax_id': '12345678901'
    }
)
print(f"QR Code URL: {payment['qr_code_url']}")
print(f"Status: {payment['status']}")
```

<Warning>
  The `expires_in` value must be between 120 seconds (2 minutes) and 172800 seconds (48 hours). Values outside this range will result in a validation error.
</Warning>

<Warning>
  If you provide the `customer` object, all fields in `metadata` (name, phone, email, tax_id) are required. Omitting any of these fields will result in a validation error.
</Warning>
