<ParamField body="amount_in_brl" type="string" required>
  Payment amount in Brazilian Reais (BRL).
</ParamField>

<ParamField body="expires_in" type="integer" required>
  Expiration time in seconds. Minimum: 120 seconds (2 minutes), Maximum: 172800 seconds (48 hours).

<ParamField body="description" type="string">
  Payment description (optional, max 255 characters).
</ParamField>

<ParamField body="idempotency_key" type="string" required>
  Unique key to prevent duplicate payments. This key also serves for idempotency - using the same `idempotency_key` will return the same payment.
</ParamField>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique payment transaction identifier |
| `amount_in_brl` | string | Payment amount in Brazilian Reais |
| `status` | string | Payment status: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELED` |
| `expires_in` | integer | Expiration time in seconds |
| `qr_code` | string | QR code image in base64 format (for display) |
| `qr_code_url` | string | PIX QR code string (for payment apps) |

<Note>
  The `qr_code` field contains a base64-encoded image that can be directly displayed in your application. The `qr_code_url` field contains the PIX QR code string that can be used by payment applications to process the payment.
</Note>

<Note>
  The `customer` field is optional. If you don't provide customer information, the payment can still be created, but customer data won't be associated with the transaction.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | PIX QR code created successfully |
| `400` | Bad request - invalid parameters or validation error |
| `401` | Unauthorized - invalid or missing API key |
| `500` | Internal server error |

## Examples

### Basic Request (Without Customer)

```javascript
async function createPixPayment(apiKey, amount, expiresIn) {
  const response = await fetch(
    'https://api.monkei.co/api/v1/transactions/payments/pix',
    {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'X-API-Key': apiKey
      },
      body: JSON.stringify({
        amount_in_brl: amount,
        expires_in: expiresIn,
        description: 'Payment for services',
        idempotency_key: `pix_${Date.now()}`
      })
    }
  );

  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Failed to create PIX payment');
  }

  const data = await response.json();
  return data.data;
}

// Usage
const payment = await createPixPayment('YOUR_API_KEY', '200.2', 3600);
console.log('QR Code URL:', payment.qr_code_url);
console.log('Status:', payment.status);
```

### Python Example

```python
import requests
import time

def create_pix_payment(api_key, amount, expires_in, customer=None):
    url = "https://api.monkei.co/api/v1/transactions/payments/pix"
    headers = {
        'Content-Type': 'application/json',
        'X-API-Key': api_key
    }
    
    payload = {
        'amount_in_brl': amount,
        'expires_in': expires_in,
        'description': 'Payment for services',
        'idempotency_key': f'pix_{int(time.time())}'
    }
    
    if customer:
        payload['customer'] = {
            'customer_id': customer.get('id'),
            'metadata': {
                'name': customer['name'],
                'phone': customer['phone'],
                'email': customer['email'],
                'tax_id': customer['tax_id']
            }
        }
    
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    
    data = response.json()
    return data['data']

# Usage
payment = create_pix_payment(
    'YOUR_API_KEY',
    '200.2',
    3600,
    {
        'id': '12345678901',
        'name': 'John Doe',
        'phone': '5511999999999',
        'email': 'customer@example.com',
        'tax_id': '12345678901'
    }
)
print(f"QR Code URL: {payment['qr_code_url']}")
print(f"Status: {payment['status']}")
```

## Use Cases

### Display QR Code in Web Application

```javascript
async function displayPixQRCode(apiKey, amount) {
  const payment = await createPixPayment(apiKey, amount, 3600);
  
  // Display QR code image

  qrCodeImage.src = `data:image/png;base64,${payment.qr_code}`;
  document.body.appendChild(qrCodeImage);
  
  return payment;
}
```

<Warning>
  The `expires_in` value must be between 120 seconds (2 minutes) and 172800 seconds (48 hours). Values outside this range will result in a validation error.
</Warning>

<Warning>
  If you provide the `customer` object, all fields in `metadata` (name, phone, email, tax_id) are required. Omitting any of these fields will result in a validation error.
</Warning>
