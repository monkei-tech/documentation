title: "USDT Payment"
openapi: "POST /api/v1/transactions/payments/usdt"
description: "Create a USDT QR code for payment"
---

<ParamField body="amount" type="integer" required>
  Payment amount in smallest unit (cents for BRL/USD). Minimum: 700 cents (R$ 7.00 or $7.00).
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code for the payment.
  Allowed values: `BRL`, `USD`.
</ParamField>

<ParamField body="expires_in" type="integer" required>
  Expiration time in seconds. Minimum: 120 seconds (2 minutes), Maximum: 1800 seconds (30 minutes).
</ParamField>

<ParamField body="description" type="string">
  Payment description (optional, max 255 characters).
</ParamField>

<ParamField body="request_id" type="string" required>
  Unique key to prevent duplicate payments. This key is a correlation identifier between your transaction and Monkei's transaction. It will be sent back in the webhook and guarantees idempotency - using the same `request_id` will return the same payment.
</ParamField>

<ParamField body="network" type="string" required>
  Blockchain network to use for the payment.
  Allowed values: `polygon`.
</ParamField>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique payment transaction identifier |
| `fiat_amount` | integer | Payment amount in fiat currency (smallest unit - cents) |
| `crypto_amount` | integer | Payment amount in USDT (smallest unit - micro-USDT, 6 decimals) |
| `status` | string | Payment status: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELED` |
| `expires_in` | integer | Expiration time in seconds |
| `qr_code` | string | QR code image in base64 format (for display) |
| `qr_code_url` | string | USDT QR code string (for payment apps) |

<Note>
  The `qr_code` field contains a base64-encoded image that can be directly displayed in your application. The `qr_code_url` field contains the USDT QR code string that can be used by payment applications to process the payment.
</Note>

<Warning>
  The `qr_code_url` address (e.g., `0x1c1C895b0D0BE6736438c7F26Fe4ab688E65D5C6`) was created specifically for this payment transaction and should **not be reused** for other payments. Each payment must use its own unique address.
</Warning>

<Note>
  The `crypto_amount` field shows the equivalent amount in USDT (in micro-USDT, 6 decimals) based on the exchange rate at the time of transaction creation. This value is locked and remains fixed until the payment expires or is completed, regardless of cryptocurrency price fluctuations.
</Note>

<Note>
  Currently, only the `polygon` network is supported for USDT payments. More networks may be added in the future.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | USDT QR code created successfully |
| `400` | Bad request - invalid parameters or validation error |
| `401` | Unauthorized - invalid or missing API key |
| `500` | Internal server error |



<Warning>
  The `expires_in` value must be between 120 seconds (2 minutes) and 1800 seconds (30 minutes). Values outside this range will result in a validation error. The maximum is limited to 30 minutes due to cryptocurrency volatility.
</Warning>

<Warning>
  Currently, only the `polygon` network is supported. Using any other network value (e.g., `ethereum`, `bsc`, `tron`) will result in an error.
</Warning>

<Note>
  The `crypto_amount` value (in micro-USDT) is locked at the time of transaction creation based on the current exchange rate. This value remains fixed until the payment expires or is completed, regardless of cryptocurrency price fluctuations.
</Note>
