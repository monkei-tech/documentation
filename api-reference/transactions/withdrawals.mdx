---
title: "Withdrawals"
openapi: "POST /api/v1/transactions/withdrawals"
description: "Initialize a new withdrawal transaction"
---

Initialize a new withdrawal transaction to transfer funds from your account to an external destination (bank account via PIX, or cryptocurrency wallet).

## Endpoint

```http
POST /api/v1/transactions/withdrawals
```

## Request Body

<ParamField body="idempotency_key" type="string" required>
  Unique key to prevent duplicate withdrawals. This key also serves for idempotency - using the same `idempotency_key` will return the same withdrawal transaction.
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code for the withdrawal. Allowed values: `BRL`, `USD`.
</ParamField>

<ParamField body="method" type="string" required>
  Withdrawal method to use. Allowed values: `PIX`, `BTC`, `USDT`.
</ParamField>

<ParamField body="amount_in_brl" type="string">
  Amount to withdraw in Brazilian Reais (BRL). Required for BRL withdrawals.
</ParamField>

<ParamField body="amount_in_crypto" type="string">
  Amount in cryptocurrency to withdraw. Required for cryptocurrency withdrawals (BTC, USDT).
</ParamField>

<ParamField body="description" type="string">
  Description for the withdrawal (optional, max 255 characters).
</ParamField>

<ParamField body="network" type="string">
  Blockchain network to use for cryptocurrency withdrawals. Required for `BTC` and `USDT` methods.
  
  Allowed values:
  - `POLYGON` - For USDT withdrawals
  - `LIGHTNING` - For BTC withdrawals
</ParamField>

<ParamField body="to_address" type="string">
  Destination address for cryptocurrency withdrawals. Required for `BTC` and `USDT` methods.
  
  <Note>
    For BTC Lightning Network withdrawals, this can be a Lightning invoice (BOLT11) or an email address (e.g., for Wallet of Satoshi). For USDT, this should be a Polygon wallet address (starting with `0x`).
  </Note>
</ParamField>

<ParamField body="pix_key" type="string">
  PIX key for PIX withdrawals. Required for `PIX` method.
  
  <Note>
    The PIX key can be an email, phone number, CPF, CNPJ, or random key depending on the `pix_key_type`.
  </Note>
</ParamField>

<ParamField body="pix_key_type" type="string">
  Type of PIX key. Required for `PIX` method.
  
  Allowed values: `EMAIL`, `PHONE`, `CPF`, `CNPJ`, `RANDOM`.
</ParamField>

<Warning>
  The required fields vary based on the withdrawal method:
  - **PIX**: `pix_key` and `pix_key_type` are required
  - **BTC**: `network` (must be `LIGHTNING`) and `to_address` are required
  - **USDT**: `network` (must be `POLYGON`) and `to_address` are required
</Warning>

<Warning>
  **Important**: USDT and BTC withdrawals are **irreversible**. Once the transaction is completed, it cannot be undone. For your first withdrawal, consider making a small test transfer to verify the destination address is correct. The minimum withdrawal amount is $10 USD. Always double-check the destination address before confirming the withdrawal.
</Warning>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.monkei.co/api/v1/transactions/withdrawals \
  --header 'Content-Type: application/json' \
  --header 'X-API-Key: YOUR_API_KEY' \

  "amount_in_brl": "100.50",
  "description": "Withdrawal to bank account",

}'
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `transaction` | object | Created withdrawal transaction information |
| `next_step` | string | Next step in the withdrawal process (typically `PROCESSING`) |

### Transaction Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique transaction identifier |
| `method` | string | Withdrawal method used: `PIX`, `BTC`, `USDT` |
| `status` | string | Transaction status: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELED` |
| `expires_in` | integer | Expiration time in seconds (may be `0` for withdrawals) |

<Note>
  The `idempotency_key` ensures that duplicate requests with the same key will return the same transaction. If a transaction with the same `idempotency_key` already exists, the API will return status `200 OK` instead of `201 Created`.
</Note>

<Note>
  For withdrawals, the `expires_in` field is typically `0` as withdrawals do not have an expiration time like payment transactions.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | Withdrawal initialized successfully |
| `200` | Withdrawal already exists (idempotency) |
| `400` | Bad request - validation error or invalid data |
| `401` | Unauthorized - invalid or missing API key |
| `404` | Not found - account not found |
| `500` | Internal server error |


<Warning>
  For cryptocurrency withdrawals, ensure that the destination address (`to_address`) is correct and belongs to the specified network. Sending funds to an incorrect address may result in permanent loss of funds. Remember: cryptocurrency withdrawals cannot be reversed.
</Warning>

<Note>
  Withdrawal limits may apply based on your account tier and verification status. The minimum withdrawal amount for cryptocurrency (USDT/BTC) is $10 USD. Check your account limits before initiating large withdrawals.
</Note>

<Note>
  PIX withdrawals are typically processed within minutes during business hours. Cryptocurrency withdrawals may take longer depending on network congestion.
</Note>
