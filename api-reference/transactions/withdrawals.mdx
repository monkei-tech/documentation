---
title: "Withdrawals"
openapi: "POST /api/v1/transactions/withdrawals"
description: "Initialize a new withdrawal transaction"
---

Initialize a new withdrawal transaction to transfer funds from your account to an external destination (bank account via PIX/DePix, or cryptocurrency wallet). PIX withdrawals currently support DePix (via Liquid Network), with traditional PIX bank transfers coming in the future.

## Endpoint

```http
POST /api/v1/transactions/withdrawals
```

## Request Body

<ParamField body="request_id" type="string" required>
  Unique key to prevent duplicate withdrawals. This key is a correlation identifier between your transaction and Monkei's transaction. It will be sent back in the webhook and guarantees idempotency - using the same `request_id` will return the same withdrawal transaction.
</ParamField>

<ParamField body="currency" type="string" required>
  Currency code for the withdrawal. Allowed values: `BRL`, `USD`.
</ParamField>

<ParamField body="method" type="string" required>
  Withdrawal method to use. Allowed values: `PIX`, `BTC`, `USDT`.
</ParamField>

<ParamField body="fiat_amount" type="integer">
  Amount to withdraw in smallest unit (cents for BRL/USD). Required for PIX withdrawals. Minimum: 1000 cents (R$ 10.00 or $10.00).
</ParamField>

<ParamField body="crypto_amount" type="integer">
  Amount in cryptocurrency to withdraw in smallest unit. Required for cryptocurrency withdrawals (BTC, USDT).
  - For BTC: amount in satoshis (8 decimals)
  - For USDT: amount in micro-USDT (6 decimals)
</ParamField>

<ParamField body="description" type="string">
  Description for the withdrawal (optional, max 255 characters).
</ParamField>

<ParamField body="network" type="string">
  Blockchain network to use for withdrawals. Required for `BTC`, `USDT`, and `PIX` (DePix) methods.
  
  Allowed values:
  - `POLYGON` - For USDT withdrawals
  - `LIGHTNING` - For BTC withdrawals
  - `LIQUID` - For PIX withdrawals via DePix (Liquid Network)
</ParamField>

<ParamField body="to_address" type="string">
  Destination address for withdrawals. Required for `BTC`, `USDT`, and `PIX` (DePix) methods.
  
  <Note>
    - For **BTC Lightning Network** withdrawals: this can be a Lightning invoice (BOLT11) or an email address (e.g., for Wallet of Satoshi).
    - For **USDT** withdrawals: this should be a Polygon wallet address (starting with `0x`).
    - For **PIX with `network="LIQUID"` (DePix)**: this should be a Liquid Network address (starting with `lq1...` for confidential addresses or `ex1...` for unconfidential addresses).
  </Note>
</ParamField>

<ParamField body="pix_key" type="string">
  PIX key for traditional PIX bank transfers. Currently, PIX withdrawals use DePix (via Liquid Network) with `to_address` and `network="LIQUID"`. Traditional PIX with `pix_key` will be available in the future.
  
  <Note>
    The PIX key can be an email, phone number, CPF, CNPJ, or random key depending on the `pix_key_type`. This field is for future use when traditional PIX bank transfers are implemented.
  </Note>
</ParamField>

<ParamField body="pix_key_type" type="string">
  Type of PIX key for traditional PIX bank transfers. Currently, PIX withdrawals use DePix (via Liquid Network). Traditional PIX with `pix_key` and `pix_key_type` will be available in the future.
  
  Allowed values: `EMAIL`, `PHONE`, `CPF`, `CNPJ`, `RANDOM`.
</ParamField>

<Warning>
  The required fields vary based on the withdrawal method:
  - **PIX**: `to_address` and `network="LIQUID"` are required (DePix mode - currently supported). Traditional PIX with `pix_key` and `pix_key_type` will be available in the future.
  - **BTC**: `network` (must be `LIGHTNING`) and `to_address` are required
  - **USDT**: `network` (must be `POLYGON`) and `to_address` are required
</Warning>

<Warning>
  **Important**: USDT, BTC, and DePix (PIX via Liquid Network) withdrawals are **irreversible**. Once the transaction is completed, it cannot be undone. For your first withdrawal, consider making a small test transfer to verify the destination address is correct. The minimum withdrawal amount is $10 USD (or R$ 10.00 for PIX). Always double-check the destination address before confirming the withdrawal.
</Warning>

<RequestExample>

**Example: DePix (PIX via Liquid Network) Withdrawal**

```bash cURL
curl --request POST \
  --url https://api.monkei.co/api/v1/transactions/withdrawals \
  --header 'Content-Type: application/json' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --data '{
  "request_id": "withdraw_depix_001",
  "currency": "BRL",
  "method": "PIX",
  "fiat_amount": 10050,
  "description": "DePix withdrawal via Liquid Network",
  "to_address": "lq1qqg8y24rukv9nmshwm20rd8qn7rw2ae2dfryv4dqj2sjhjww8d7nza2x8v0w7neggsfe0e998kaz6ktxzm39eqhhd3tejeglec",
  "network": "LIQUID"
}'
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `transaction` | object | Created withdrawal transaction information |
| `next_step` | string | Next step in the withdrawal process (typically `PROCESSING`) |

### Transaction Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string (UUID) | Unique transaction identifier |
| `method` | string | Withdrawal method used: `PIX`, `BTC`, `USDT` |
| `status` | string | Transaction status: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELED` |
| `expires_in` | integer | Expiration time in seconds (may be `0` for withdrawals) |

<Note>
  The `request_id` ensures that duplicate requests with the same key will return the same transaction. If a transaction with the same `request_id` already exists, the API will return status `200 OK` instead of `201 Created`.
</Note>

<Note>
  For withdrawals, the `expires_in` field is typically `0` as withdrawals do not have an expiration time like payment transactions.
</Note>

## Status Codes

| Code | Description |
|------|-------------|
| `201` | Withdrawal initialized successfully |
| `200` | Withdrawal already exists (idempotency) |
| `400` | Bad request - validation error or invalid data |
| `401` | Unauthorized - invalid or missing API key |
| `404` | Not found - account not found |
| `500` | Internal server error |


<Warning>
  For cryptocurrency withdrawals, ensure that the destination address (`to_address`) is correct and belongs to the specified network. Sending funds to an incorrect address may result in permanent loss of funds. Remember: cryptocurrency withdrawals cannot be reversed.
</Warning>

<Note>
  Withdrawal limits may apply based on your account tier and verification status. The minimum withdrawal amount for cryptocurrency (USDT/BTC) is $10 USD. Check your account limits before initiating large withdrawals.
</Note>

<Note>
  PIX withdrawals currently use DePix (via Liquid Network) and are processed on the blockchain. Traditional PIX bank transfers will be available in the future and will be processed within minutes during business hours. Cryptocurrency withdrawals may take longer depending on network congestion.
</Note>
