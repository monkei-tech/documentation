# Autenticação

A API v1 do Monkei Gateway usa autenticação via Bearer Token (JWT) para todos os endpoints.

## Visão Geral

<Note>
  Todos os endpoints da API v1 requerem autenticação. Você precisará de uma API Key válida para fazer requisições.
</Note>

## Obtendo uma API Key

<Steps>
  <Step title="Acesse o Dashboard">
    Faça login em [dashboard.monkei.com](https://dashboard.monkei.com)
  </Step>
  <Step title="Vá para API Keys">
    Navegue para **Configurações > API Keys**
  </Step>
  <Step title="Crie uma nova chave">
    Clique em **"Nova API Key"** e escolha o ambiente
  </Step>
  <Step title="Copie a chave">
    **Importante**: A chave só é exibida uma vez!
  </Step>
</Steps>

## Usando a API Key

### Header Authorization

Inclua sua API Key no header `Authorization` de todas as requisições:

```bash
curl -H "Authorization: Bearer sk_live_1234567890abcdef" \
     https://api.monkei.com/api/v1/transactions/payments
```

### Exemplo com JavaScript

```javascript
const response = await fetch('https://api.monkei.com/api/v1/transactions/payments', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_1234567890abcdef',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount_in_brl: 10050,
    description: 'Pagamento de produto XYZ',
    idempotency_key: 'pix_123456789'
  })
});
```

## Segurança

<Warning>
  **Nunca exponha suas chaves de API** em código frontend ou repositórios públicos.
</Warning>

### Boas Práticas

<AccordionGroup>
  <Accordion title="Armazenamento Seguro">
    - Armazene chaves em variáveis de ambiente
    - Use serviços de gerenciamento de segredos em produção
    - Nunca commite chaves no controle de versão
  </Accordion>
  
  <Accordion title="Rotação de Chaves">
    - Rotacione chaves regularmente
    - Monitore uso das chaves
    - Revogue chaves comprometidas imediatamente
  </Accordion>
  
  <Accordion title="HTTPS Obrigatório">
    - Sempre use HTTPS em produção
    - Valide certificados SSL
    - Use TLS 1.2 ou superior
  </Accordion>
</AccordionGroup>

## Exemplos de Implementação

### Node.js

```javascript
const axios = require('axios');

class MonkeiAPI {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.baseURL = 'https://api.monkei.com';
  }

  async makeRequest(method, endpoint, data = null) {
    try {
      const response = await axios({
        method,
        url: `${this.baseURL}${endpoint}`,
        headers: {
          'Authorization': `Bearer ${this.apiKey}`,
          'Content-Type': 'application/json'
        },
        data
      });
      
      return response.data;
    } catch (error) {
      console.error('Erro na API:', error.response?.data);
      throw error;
    }
  }

  async createPixPayment(amount, description, idempotencyKey) {
    return this.makeRequest('POST', '/api/v1/transactions/payments/pix', {
      amount_in_brl: amount,
      description,
      idempotency_key: idempotencyKey
    });
  }
}

// Exemplo de uso
const api = new MonkeiAPI(process.env.MONKEI_API_KEY);
const payment = await api.createPixPayment(10050, 'Pagamento de produto XYZ', 'pix_123456789');
```

### Python

```python
import requests
import os

class MonkeiAPI:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://api.monkei.com"
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        }
    
    def make_request(self, method, endpoint, data=None):
        url = f"{self.base_url}{endpoint}"
        
        response = requests.request(
            method=method,
            url=url,
            headers=self.headers,
            json=data
        )
        
        response.raise_for_status()
        return response.json()
    
    def create_pix_payment(self, amount, description, idempotency_key):
        return self.make_request(
            'POST',
            '/api/v1/transactions/payments/pix',
            {
                'amount_in_brl': amount,
                'description': description,
                'idempotency_key': idempotency_key
            }
        )

# Exemplo de uso
api = MonkeiAPI(os.getenv('MONKEI_API_KEY'))
payment = api.create_pix_payment(10050, 'Pagamento de produto XYZ', 'pix_123456789')
```

### PHP

```php
<?php
class MonkeiAPI {
    private $apiKey;
    private $baseUrl = 'https://api.monkei.com';
    
    public function __construct($apiKey) {
        $this->apiKey = $apiKey;
    }
    
    private function makeRequest($method, $endpoint, $data = null) {
        $url = $this->baseUrl . $endpoint;
        
        $ch = curl_init();
        curl_setopt($ch, CURLOPT_URL, $url);
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'Authorization: Bearer ' . $this->apiKey,
            'Content-Type: application/json'
        ]);
        
        if ($method === 'POST') {
            curl_setopt($ch, CURLOPT_POST, true);
            curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
        }
        
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        if ($httpCode >= 400) {
            throw new Exception('API Error: ' . $response);
        }
        
        return json_decode($response, true);
    }
    
    public function createPixPayment($amount, $description, $idempotencyKey) {
        return $this->makeRequest('POST', '/api/v1/transactions/payments/pix', [
            'amount_in_brl' => $amount,
            'description' => $description,
            'idempotency_key' => $idempotencyKey
        ]);
    }
}

// Exemplo de uso
$api = new MonkeiAPI($_ENV['MONKEI_API_KEY']);
$payment = $api->createPixPayment(10050, 'Pagamento de produto XYZ', 'pix_123456789');
?>
```
