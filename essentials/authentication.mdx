The Monkei Gateway API v1 uses Bearer Token (JWT) authentication for all endpoints.

## Overview

<Note>
  All API v1 endpoints require authentication. You will need a valid API Key to make requests.
</Note>

## Getting an API Key

<Steps>
  <Step title="Access the Dashboard">
    Log in to [app.monkei.co](https://app.monkei.co) and go to **Integrations > API Keys**.
    
    ![API Keys Dashboard](/images/api_key_stat.png)
  </Step>
  <Step title="Create a new key">
    Click on **"New API Key"**, choose the environment (Production or Test) and give it a name.
    
    ![Create API Key Modal](/images/api_key_modal.png)
  </Step>
  <Step title="Copy the key">
    **Important**: The key is shown only once! Copy it and store it securely.
    
    ![API Key Created](/images/api_key_created.png)
  </Step>
</Steps>

## Using the API Key

### Authorization Header

Include your API Key in the `Authorization` header of all requests:

```bash
curl -H "Authorization: Bearer sk_live_1234567890abcdef" \
     https://api.monkei.com/api/v1/transactions/payments
```

### JavaScript Example

```javascript
const response = await fetch('https://api.monkei.com/api/v1/transactions/payments', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_live_1234567890abcdef',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount_in_brl: 10050,
    description: 'Payment for product XYZ',
    idempotency_key: 'pix_123456789'
  })
});
```

## Security

<Warning>
  **Never expose your API keys** in frontend code or public repositories.
</Warning>

### Best Practices

<AccordionGroup>
  <Accordion title="Secure Storage">
    - Store keys in environment variables
    - Use secret management services in production
    - Never commit keys to version control
  </Accordion>
  
  <Accordion title="Key Rotation">
    - Rotate keys regularly
    - Monitor key usage
    - Revoke compromised keys immediately
  </Accordion>
  
  <Accordion title="Mandatory HTTPS">
    - Always use HTTPS in production
    - Validate SSL certificates
    - Use TLS 1.2 or higher
  </Accordion>
</AccordionGroup>

## Implementation Examples

### Node.js

```javascript
const axios = require('axios');

class MonkeiAPI {
  constructor(apiKey) {
    this.apiKey = apiKey;
    this.baseURL = 'https://api.monkei.com';
  }

  async makeRequest(method, endpoint, data = null) {
    try {
      const response = await axios({
        method,
        url: `${this.baseURL}${endpoint}`,
        headers: {
          'Authorization': `Bearer ${this.apiKey}`,
          'Content-Type': 'application/json'
        },
        data
      });
      
      return response.data;
    } catch (error) {
      console.error('Erro na API:', error.response?.data);
      throw error;
    }
  }

  async createPixPayment(amount, description, idempotencyKey) {
    return this.makeRequest('POST', '/api/v1/transactions/payments/pix', {
      amount_in_brl: amount,
      description,
      idempotency_key: idempotencyKey
    });
  }
}

// Exemplo de uso
const api = new MonkeiAPI(process.env.MONKEI_API_KEY);
const payment = await api.createPixPayment(10050, 'Pagamento de produto XYZ', 'pix_123456789');
```

### Python

```python
import requests
import os

class MonkeiAPI:
    def __init__(self, api_key):
        self.api_key = api_key
        self.base_url = "https://api.monkei.com"
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json"
        }
    
    def make_request(self, method, endpoint, data=None):
        url = f"{self.base_url}{endpoint}"
        
        response = requests.request(
            method=method,
            url=url,
            headers=self.headers,
            json=data
        )
        
        response.raise_for_status()
        return response.json()
    
    def create_pix_payment(self, amount, description, idempotency_key):
        return self.make_request(
            'POST',
            '/api/v1/transactions/payments/pix',
            {
                'amount_in_brl': amount,
                'description': description,
                'idempotency_key': idempotency_key
            }
        )

# Exemplo de uso
api = MonkeiAPI(os.getenv('MONKEI_API_KEY'))
payment = api.create_pix_payment(10050, 'Pagamento de produto XYZ', 'pix_123456789')
```

### PHP

```php
<?php
class MonkeiAPI {
    private $apiKey;
    private $baseUrl = 'https://api.monkei.com';
    
    public function __construct($apiKey) {
        $this->apiKey = $apiKey;
    }
    
    private function makeRequest($method, $endpoint, $data = null) {
        $url = $this->baseUrl . $endpoint;
        
        $ch = curl_init();
        curl_setopt($ch, CURLOPT_URL, $url);
        curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
        curl_setopt($ch, CURLOPT_HTTPHEADER, [
            'Authorization: Bearer ' . $this->apiKey,
            'Content-Type: application/json'
        ]);
        
        if ($method === 'POST') {
            curl_setopt($ch, CURLOPT_POST, true);
            curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
        }
        
        $response = curl_exec($ch);
        $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
        curl_close($ch);
        
        if ($httpCode >= 400) {
            throw new Exception('API Error: ' . $response);
        }
        
        return json_decode($response, true);
    }
    
    public function createPixPayment($amount, $description, $idempotencyKey) {
        return $this->makeRequest('POST', '/api/v1/transactions/payments/pix', [
            'amount_in_brl' => $amount,
            'description' => $description,
            'idempotency_key' => $idempotencyKey
        ]);
    }
}

// Exemplo de uso
$api = new MonkeiAPI($_ENV['MONKEI_API_KEY']);
$payment = $api->createPixPayment(10050, 'Pagamento de produto XYZ', 'pix_123456789');
?>
```
